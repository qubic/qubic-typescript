---
title: Transfers & contract calls
description: buildTransaction and buildContractCall — high-level signed transaction builders.
---

Both methods return `SignedTransaction`: `{ encoded, hash, bytes }`. `encoded` is the base64 transaction ready to broadcast; `hash` is the canonical `TxHash`; `bytes` are the raw signed bytes.

## `wallet.buildTransaction(params)`

Builds and signs a QU transfer.

```ts
import { createWallet, generateSeed } from "@qubic.org/wallet"
import { createLiveClient } from "@qubic.org/rpc"
import { toIdentity } from "@qubic.org/types"

const live = createLiveClient()
const wallet = createWallet(generateSeed())
const { tick } = await live.getTickInfo()

const { encoded, hash } = await wallet.buildTransaction({
  destination: toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL"),
  amount: 1_000_000n,
  targetTick: tick + 5,
  currentTick: tick,
})

await live.broadcastTransaction(encoded)
console.log("TX hash:", hash)
```

**Parameters**

| Name | Type | Required | Description |
|---|---|---|---|
| `destination` | `Identity` | Yes | Recipient identity |
| `amount` | `bigint` | Yes | QU to send |
| `targetTick` | `number` | Yes | Tick by which node must process the TX |
| `currentTick` | `number` | No | Current tick; when provided, throws `TickInThePastError` if `targetTick <= currentTick` |

**Returns** `Promise<SignedTransaction>` — `{ encoded: Base64, hash: TxHash, bytes: Uint8Array }`

## `wallet.buildContractCall(params)`

Builds and signs a smart contract procedure call.

```ts
import { QEARN_LOCK_INPUT_TYPE } from "@qubic.org/contracts"

const { encoded, hash } = await wallet.buildContractCall({
  amount: 10_000_000n,
  targetTick: tick + 5,
  inputType: QEARN_LOCK_INPUT_TYPE,
  payload: new Uint8Array(0),  // lock has no input fields
})
```

The destination defaults to `SC_DESTINATION` (the all-A identity — the zero address for all SC calls). Each contract is identified by its `inputType`, not by address.

**Parameters**

| Name | Type | Required | Description |
|---|---|---|---|
| `destination` | `Identity` | No | Override the SC destination. Defaults to the all-A identity. |
| `amount` | `bigint` | No | QU attached to the call. Defaults to `0n`. |
| `targetTick` | `number` | Yes | Tick deadline |
| `currentTick` | `number` | No | Current tick; when provided, throws `TickInThePastError` if `targetTick <= currentTick` |
| `inputType` | `number` | Yes | Procedure input type constant |
| `payload` | `Uint8Array` | Yes | Encoded procedure input |

**Returns** `Promise<SignedTransaction>` — `{ encoded: Base64, hash: TxHash, bytes: Uint8Array }`

## `wallet.identity`

The Qubic identity derived from the wallet's seed. Read-only.

```ts
const wallet = createWallet(seed)
console.log(wallet.identity) // Identity — 60 uppercase chars
```

---

## `wallet.publicKey`

The 32-byte FourQ public key derived from the wallet's seed. Useful for low-level TCP calls.

```ts
const pk: Uint8Array = wallet.publicKey
```
