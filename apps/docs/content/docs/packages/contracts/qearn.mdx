---
title: Qearn
description: Staking protocol that locks QUBIC for one epoch to earn yield, with early-unlock and burn mechanics.
---

Qearn (contract index `9`) is an epoch-based staking protocol. Users lock QUBIC into the contract at any point during an epoch. When the epoch ends, locked funds earn yield from a bonus pool. Unlocking before the epoch ends returns principal minus a penalty that is partially burned.

Import the namespace:

```ts
import { qearn } from "@qubic.org/contracts"
```

---

## Procedures (write)

Procedures are invoked via transactions. Build the payload with a builder, then send with `wallet.buildScTransaction`.

### Lock

Locks QUBIC into Qearn for the current epoch. The transaction `amount` field is the amount being locked — the payload is empty. Set `inputType` to `QEARN_LOCK_INPUT_TYPE` (1) and omit a payload.

```ts
import { QEARN_LOCK_INPUT_TYPE } from "@qubic.org/contracts"

// No payload builder — the lock amount comes from the transaction amount field
// wallet.buildScTransaction({ ..., inputType: QEARN_LOCK_INPUT_TYPE, payload: new Uint8Array(0) })
```

**Lock output** (returned in transaction result)

| Field | Type | Description |
|---|---|---|
| `returnCode` | `number` | `0` on success, non-zero on failure. |

Decode with: `qearn.decodeLockOutput(bytes)`

---

### Unlock

Unlocks a previously locked position. Early unlock incurs a penalty; amounts held until epoch end receive full yield.

```ts
const payload = qearn.buildUnlockInput({
  amount: 10_000_000n,    // amount to unlock (bigint)
  lockedEpoch: 213,       // the epoch in which you originally locked
})
```

**Input**

| Field | Type | Description |
|---|---|---|
| `amount` | `bigint` | Amount to unlock. |
| `lockedEpoch` | `number` | Epoch number of the original lock. |

**Unlock output**

| Field | Type | Description |
|---|---|---|
| `returnCode` | `number` | `0` on success, non-zero on failure. |

Decode with: `qearn.decodeUnlockOutput(bytes)`

## Read functions (callers)

Callers return `Promise<Result<Output, QubicRpcError>>`. Check `result.ok` before using `result.value`.

### `getLockInfoPerEpoch`

Returns totals for a single epoch.

```ts
const result = await qearn.getLockInfoPerEpoch(live, { Epoch: 213 })
```

**Input:** `{ Epoch: number }`

**Output**

| Field | Type | Description |
|---|---|---|
| `lockedAmount` | `bigint` | Total QUBIC locked at epoch start. |
| `bonusAmount` | `bigint` | Bonus pool at epoch start. |
| `currentLockedAmount` | `bigint` | Current total locked (decreases as users unlock early). |
| `currentBonusAmount` | `bigint` | Current bonus pool. |
| `yield` | `bigint` | Projected yield in basis points. |

---

### `getUserLockedInfo`

Returns the locked amount for a specific user and epoch.

```ts
const result = await qearn.getUserLockedInfo(
  live,
  { user: identity, epoch: 213 },
  { identityToPublicKey },
)
```

**Input:** `{ user: string, epoch: number }`

**Output**

| Field | Type | Description |
|---|---|---|
| `lockedAmount` | `bigint` | Amount locked by this user for this epoch. |

---

### `getStateOfRound`

Returns the state of a round as a numeric code.

```ts
const result = await qearn.getStateOfRound(live, { epoch: 213 })
```

**Input:** `{ epoch: number }`

**Output**

| Field | Type | Description |
|---|---|---|
| `state` | `number` | Round state code. `0` = not started, `1` = open, `2` = ended. |

---

### `getUserLockStatus`

Returns a bitmask of which epochs a user has active locks in.

```ts
const result = await qearn.getUserLockStatus(
  live,
  { user: identity },
  { identityToPublicKey },
)
```

**Input:** `{ user: string }`

**Output**

| Field | Type | Description |
|---|---|---|
| `status` | `bigint` | Bitmask — bit N is set if the user has a lock in epoch N. |

---

### `getEndedStatus`

Returns the final unlock summary for a user after a lock round ends.

```ts
const result = await qearn.getEndedStatus(
  live,
  { user: identity },
  { identityToPublicKey },
)
```

**Input:** `{ user: string }`

**Output**

| Field | Type | Description |
|---|---|---|
| `fullyUnlockedAmount` | `bigint` | Funds unlocked at epoch end (with full reward). |
| `fullyRewardedAmount` | `bigint` | Reward received for full-term locks. |
| `earlyUnlockedAmount` | `bigint` | Funds unlocked early (with penalty). |
| `earlyRewardedAmount` | `bigint` | Reward (net of penalty) for early unlocks. |

---

### `getStatsPerEpoch`

Returns epoch-level statistics.

```ts
const result = await qearn.getStatsPerEpoch(live, { epoch: 213 })
```

**Input:** `{ epoch: number }`

**Output**

| Field | Type | Description |
|---|---|---|
| `earlyUnlockedAmount` | `bigint` | Total early-unlocked in this epoch. |
| `earlyUnlockedPercent` | `bigint` | Percentage of total that was unlocked early. |
| `totalLockedAmount` | `bigint` | Total locked at epoch start. |
| `averageAPY` | `bigint` | Average APY in basis points. |

---

### `getBurnedAndBoostedStats`

Returns lifetime burn and boost statistics across all epochs.

```ts
const result = await qearn.getBurnedAndBoostedStats(live)
```

**Output**

| Field | Type | Description |
|---|---|---|
| `burnedAmount` | `bigint` | Total QUBIC burned from penalties. |
| `averageBurnedPercent` | `bigint` | Average burn rate in basis points. |
| `boostedAmount` | `bigint` | Total QUBIC boosted from bonus pool. |
| `averageBoostedPercent` | `bigint` | Average boost rate in basis points. |
| `rewardedAmount` | `bigint` | Total QUBIC rewarded to stakers. |
| `averageRewardedPercent` | `bigint` | Average reward rate in basis points. |

---

### `getBurnedAndBoostedStatsPerEpoch`

Returns burn and boost statistics for a single epoch.

**Output**

| Field | Type | Description |

| `boostedAmount` | `bigint` | QUBIC boosted in this epoch. |
| `boostedPercent` | `bigint` | Boost rate in basis points. |
| `rewardedAmount` | `bigint` | QUBIC rewarded in this epoch. |
| `rewardedPercent` | `bigint` | Reward rate in basis points. |

## Complete example: lock and check status

```ts
import { qearn } from "@qubic.org/contracts"
import { createLiveClient } from "@qubic.org/rpc"
import { identityToPublicKey } from "@qubic.org/crypto"

const live = createLiveClient()
const identity = "YOUR_IDENTITY_HERE"

// Check current epoch info before locking
const epochInfo = await qearn.getLockInfoPerEpoch(live, { Epoch: 213 })
if (!epochInfo.ok) throw epochInfo.error

console.log("Current locked:", epochInfo.value.currentLockedAmount.toString())
console.log("Projected yield:", epochInfo.value.yield.toString(), "bps")

// Lock has no input payload — the amount goes in the transaction amount field

// Check the user's existing lock status
const lockStatus = await qearn.getUserLockStatus(
  live,
  { user: identity },
  { identityToPublicKey },
)

if (lockStatus.ok) {
  console.log("Lock bitmask:", lockStatus.value.status.toString(2))
}

// --- send the lock transaction separately via your wallet ---

//   inputType: QEARN_LOCK_INPUT_TYPE,
//   payload: new Uint8Array(0),    // no payload for lock
// })
```
