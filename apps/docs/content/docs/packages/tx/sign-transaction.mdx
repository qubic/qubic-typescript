## `signTransaction(unsigned, seed)`

Signs the unsigned transaction bytes from `buildTransaction` with a SchnorrQ signature, and appends the 64-byte signature to the end.

```ts
import { buildTransaction, signTransaction } from "@qubic.org/tx"
import { toSeed } from "@qubic.org/types"

const seed = toSeed("...")
const unsigned = buildTransaction({ ... })

const signed: Uint8Array = await signTransaction(unsigned, seed)
// signed = unsigned (≥80 B) + signature (64 B)
```

<Callout>
  `signTransaction` is async — it delegates to `sign` in `@qubic.org/crypto`. Always `await` it.
</Callout>

**Parameters**

| Name | Type | Description |
|---|---|---|
| `unsigned` | `Uint8Array` | Output of `buildTransaction` |
| `seed` | `Seed` | 55-character lowercase seed |

**Returns** `Promise<Uint8Array>` — signed transaction bytes (header + payload + 64-byte signature).

---

## `encodeTransaction(signed)`

Base64-encodes signed transaction bytes for the RPC broadcast endpoint.

```ts
import { encodeTransaction } from "@qubic.org/tx"

const encoded: Base64 = encodeTransaction(signed)
await live.broadcastTransaction(encoded)
```

**Returns** `Base64` — standard base64 string.

---

## `computeTransactionHash(signed)`

Computes the canonical transaction hash: K12 of the signed bytes, returned as a 60-character base-26 `TxHash`. Use this to look the transaction up in the archive after broadcasting.

```ts
import { computeTransactionHash } from "@qubic.org/tx"

const hash: TxHash = computeTransactionHash(signed)
const result = await archive.getTransactionByHash(hash)
```

**Returns** `TxHash` — 60-character lowercase string (a–z alphabet, not hex).

---

## `verifyTransactionSignature(signedTxBytes)`

Verifies the SchnorrQ signature on signed transaction bytes. Reads the public key embedded in the transaction bytes — no second argument required.

```ts
import { verifyTransactionSignature } from "@qubic.org/tx"

const valid: boolean = verifyTransactionSignature(signed)
// synchronous — no await needed
```

**Returns** `boolean` — `true` if the signature is valid.

---

## Complete sign-and-broadcast flow

```ts
import { buildTransaction, signTransaction, encodeTransaction, computeTransactionHash } from "@qubic.org/tx"
import { publicKeyFromSeed } from "@qubic.org/crypto"
import { toSeed } from "@qubic.org/types"
import { createLiveClient } from "@qubic.org/rpc"

const live = createLiveClient()
const seed = toSeed(process.env.SEED!)
const tickResult = await live.getTickInfo()
if (!tickResult.ok) throw tickResult.error

const unsigned = buildTransaction({
  source: publicKeyFromSeed(seed),
  destination: new Uint8Array(32),
  amount: 0n,
  targetTick: tickResult.value.tick + 5,
  inputType: 0,
})

const signed = await signTransaction(unsigned, seed)
const encoded = encodeTransaction(signed)
const hash = computeTransactionHash(signed)

await live.broadcastTransaction(encoded)
console.log("TX hash:", hash)
```
