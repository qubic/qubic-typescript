Qubic uses **SchnorrQ** signatures over the **FourQ** elliptic curve. This is not secp256k1 (Bitcoin/Ethereum) and not Ed25519. Keys and signatures produced here are not compatible with other blockchain systems.

Both `sign` and `verify` are async. The underlying SchnorrQ implementation runs in a WASM module that may need to initialize on first call — always `await` them.

## `sign(data, seed)`

Signs arbitrary bytes using the private key derived from a seed. Returns a 64-byte SchnorrQ signature.

```ts
import { sign } from "@qubic.org/crypto"
import { toSeed } from "@qubic.org/types"

const seed = toSeed("aaaaabbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb")
const message = new TextEncoder().encode("hello qubic")

const signature: Uint8Array = await sign(message, seed)
// signature.length === 64
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `data` | `Uint8Array` | The bytes to sign |
| `seed` | `Seed` | 55-character lowercase seed |

**Returns** `Promise<Uint8Array>` — 64-byte SchnorrQ signature.

---

## `verify(data, signature, publicKey)`

Verifies a SchnorrQ signature against a public key and message. Returns `true` if the signature is valid for the given data and key.

```ts
import { sign, verify, publicKeyFromSeed } from "@qubic.org/crypto"
import { toSeed } from "@qubic.org/types"

const seed = toSeed("aaaaabbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb")
const publicKey = publicKeyFromSeed(seed)
const message = new TextEncoder().encode("hello qubic")

const sig = await sign(message, seed)
const valid = await verify(message, sig, publicKey)
// valid === true
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `data` | `Uint8Array` | The original signed bytes |
| `signature` | `Uint8Array` | 64-byte SchnorrQ signature |
| `publicKey` | `Uint8Array` | 32-byte FourQ public key |

**Returns** `Promise<boolean>`

## Transaction signing

For signing Qubic transactions, use `signTransaction` from `@qubic.org/tx` instead. It serializes the transaction header before signing, appends the signature, and returns the complete signed bytes ready for broadcast.

```ts
import { buildTransaction, signTransaction } from "@qubic.org/tx"
import { toSeed } from "@qubic.org/types"

const seed = toSeed("...")
const unsigned = buildTransaction({ ... })
const signed: Uint8Array = await signTransaction(unsigned, seed)
```

`sign` is useful when you need to sign an arbitrary message outside of the transaction format, for example to prove ownership of an identity off-chain or to sign a custom data structure for a protocol extension.
