## `computeTransactionHash(txBytes)`

Computes the canonical transaction hash: K12 of the signed transaction bytes, truncated to 32 bytes, encoded as a 60-character lowercase base-26 string (letters a–z, not hex). Use this to look the transaction up in the archive after broadcasting.

```ts
import { computeTransactionHash } from "@qubic.org/tx"

const hash: TxHash = computeTransactionHash(signed)
// Use to poll the archive for confirmation
const result = await archive.getTransactionByHash(hash)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `txBytes` | `Uint8Array` | Signed transaction bytes |

**Returns** `TxHash` — 60-character lowercase base-26 string (letters a–z, same alphabet as Qubic identity encoding but lowercase).
