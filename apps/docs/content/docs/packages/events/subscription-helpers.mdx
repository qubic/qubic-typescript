---
title: Subscription helpers
description: subscribeQuTransfers, subscribeAssetEvents, subscribeContractLogs, subscribeAllEvents — pre-filtered, decoded event streams.
---

These four helpers wrap `bob.subscription.subscribeLogs` with pre-applied log type filters and automatic `decodeEvent` calls. Each returns an `AsyncIterable<SubscriptionEvent<TypedEvent>>` that yields fully decoded events.

Use them instead of calling `subscribeLogs` directly when you want a type-safe stream for a specific event category.

```ts
import {
  subscribeQuTransfers,
  subscribeAssetEvents,
  subscribeContractLogs,
  subscribeAllEvents,
} from "@qubic.org/events"
import { createBobClient } from "@qubic.org/bob"

const bob = createBobClient({ baseUrl: "http://localhost:40420" })
```

All four share the same iteration pattern:

```ts
for await (const { data, isCatchUp, logId } of subscribeX(bob.subscription, filter?, options?)) {
  if (isCatchUp) continue   // skip historical replay events
  // data is a TypedEvent — discriminate on data.logType
}
```

---

## `subscribeQuTransfers(bob, filter?, options?)`

Subscribes to QU transfer events (log type 0). Each event is decoded and narrowed to `TypedEvent & { logType: 0 }`, giving you typed access to `data.source`, `data.destination`, and `data.amount`.

```ts
import { subscribeQuTransfers } from "@qubic.org/events"
import { toIdentity } from "@qubic.org/types"

const identity = toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL")
const ac = new AbortController()

for await (const event of subscribeQuTransfers(
  bob.subscription,
  { identity },
  { signal: ac.signal },
)) {
  if (event.isCatchUp) continue

  const { source, destination, amount } = event.data.data
  const dir = source === identity ? "OUT" : "IN"
  console.log(`[tick ${event.data.tick}] [${dir}] ${amount}n QU`)
  console.log(`  ${source} -> ${destination}`)
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `bob` | `BobSubscriptionClient` | Subscription client |
| `filter` | `Omit<EventFilter, 'logTypes'>` | Optional filter — identity, contract, tick range |
| `options.startLogId` | `bigint` | Resume from this log ID |
| `options.startEpoch` | `number` | Start from the beginning of this epoch |
| `options.signal` | `AbortSignal` | Stops the iteration when aborted |

**Yields** `SubscriptionEvent<TypedEvent & { logType: 0 }>` — `event.data.data` has `source`, `destination`, `amount`.

## `subscribeAssetEvents(bob, filter?, options?)`

Subscribes to all asset-related log types: issuance (1), ownership change (2), possession change (3), ownership managing contract change (11), and possession managing contract change (12).

```ts
import { subscribeAssetEvents, LOG_TYPE } from "@qubic.org/events"

for await (const event of subscribeAssetEvents(bob.subscription, { identity })) {
  if (event.isCatchUp) continue

  const typed = event.data

  if (typed.logType === LOG_TYPE.ASSET_ISSUANCE) {
    console.log("New asset:", typed.data.assetName, "shares:", typed.data.numberOfShares)
  } else if (typed.logType === LOG_TYPE.ASSET_OWNERSHIP_CHANGE) {
    console.log(
      typed.data.assetName,
      "ownership:",
      typed.data.source,
      "->",
      typed.data.destination,
    )
  }
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `bob` | `BobSubscriptionClient` | Subscription client |
| `filter` | `Omit<EventFilter, 'logTypes'>` | Optional filter |
| `options` | `SubOptions` | `startLogId`, `startEpoch`, `signal` |

**Yields** `SubscriptionEvent<TypedEvent>` — switch on `event.data.logType` to narrow.

## `subscribeContractLogs(bob, filter?, options?)`

Subscribes to smart contract message log types: error (4), warning (5), information (6), and debug (7).

```ts
import { subscribeContractLogs, LOG_TYPE } from "@qubic.org/events"

for await (const event of subscribeContractLogs(bob.subscription, { contractIndex: 9 })) {
  if (event.isCatchUp) continue

  const typed = event.data

  if (typed.logType === LOG_TYPE.CONTRACT_ERROR_MESSAGE) {
    console.error(
      `Contract ${typed.data.contractIndex} error (type ${typed.data.contractMessageType})`
    )
  } else if (typed.logType === LOG_TYPE.CONTRACT_INFORMATION_MESSAGE) {
    console.log(
      `Contract ${typed.data.contractIndex} info (type ${typed.data.contractMessageType})`
    )
  }
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `bob` | `BobSubscriptionClient` | Subscription client |
| `filter` | `Omit<EventFilter, 'logTypes'>` | Optional filter |
| `options` | `SubOptions` | `startLogId`, `startEpoch`, `signal` |

**Yields** `SubscriptionEvent<TypedEvent>` — `event.data.data` has `contractIndex` and `contractMessageType`.

## `subscribeAllEvents(bob, filter?, options?)`

Subscribes to every log type and decodes each event. Apply a filter to narrow the stream.

```ts
import { subscribeAllEvents, eventFilter, LOG_TYPE } from "@qubic.org/events"

const filter = eventFilter()
  .ofTypes(LOG_TYPE.BURNING, LOG_TYPE.DUST_BURNING)
  .build()

for await (const event of subscribeAllEvents(bob.subscription, filter)) {
  if (event.isCatchUp) continue

  const typed = event.data

  if (typed.logType === LOG_TYPE.BURNING) {
    console.log("Burned:", typed.data.amount, "QU from", typed.data.source)
  } else if (typed.logType === LOG_TYPE.DUST_BURNING) {
    console.log("Dust burn:", typed.data.burns.length, "accounts")
  }
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `bob` | `BobSubscriptionClient` | Subscription client |
| `filter` | `EventFilter` | Optional filter including `logTypes` |
| `options` | `SubOptions` | `startLogId`, `startEpoch`, `signal` |

**Yields** `SubscriptionEvent<TypedEvent>` — switch on `event.data.logType` to narrow.

## Catch-up events

When a subscription starts or reconnects after a gap, Bob delivers buffered historical events before switching to live. These have `isCatchUp: true`. The subscription client tracks the last received `logId` across reconnects, so the replay resumes from where it left off rather than from the beginning.

Skip catch-up events when you only need live data:

```ts
for await (const event of subscribeAllEvents(bob.subscription)) {
  if (event.isCatchUp) continue
  // only live events
}
```

Process them when you want a complete history starting from a known point:

```ts
for await (const event of subscribeQuTransfers(
  bob.subscription,
  undefined,
  { startEpoch: 150 },
)) {
  // isCatchUp: true until live; process all
  processTransfer(event.data)
}
```

## Watching multiple identities

Each helper call creates an independent subscription. Run them in parallel with `Promise.all`.

```ts
import { subscribeQuTransfers } from "@qubic.org/events"
import { toIdentity } from "@qubic.org/types"

const identities = [
  toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL"),
  toIdentity("ABCDEFGHIJKLMNOPQRSTUVWXYZABCDEFGHIJKLMNOPQRSTUVWXYZABCDEFGHIJ"),
]

const ac = new AbortController()

async function watch(identity: ReturnType<typeof toIdentity>) {
  for await (const event of subscribeQuTransfers(
    bob.subscription,
    { identity },
    { signal: ac.signal },
  )) {
    if (event.isCatchUp) continue
    console.log(identity.slice(0, 8), event.data.data.amount)
  }
}

await Promise.all(identities.map(watch))
```
