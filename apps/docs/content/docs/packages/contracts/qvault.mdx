title: QVault
description: Governance and treasury contract — stake QCAP to vote on proposals that control protocol fund allocation.
---

QVault (contract index `10`) is Qubic's governance and treasury contract. QCAP holders stake their tokens to gain voting power, then submit and vote on proposals that direct how protocol funds are deployed — including investments in QEarn, market-making, and IPO participation.

Import the namespace:

```ts
import { qVAULT } from "@qubic.org/contracts"
```

---

## Procedures (write)

### Stake

Stakes QCAP to earn voting power.

```ts
const payload = qVAULT.buildStakeInput({ amount: 100 })
```

**Input:** `{ amount: number }` — QCAP units to stake.

**Output:** `{ returnCode: number }` — decode with `qVAULT.decodeStakeOutput(bytes)`

---

### UnStake

Returns staked QCAP.

```ts
const payload = qVAULT.buildUnStakeInput({ amount: 100 })
```

**Input:** `{ amount: number }` — QCAP units to unstake.

**Output:** `{ returnCode: number }` — decode with `qVAULT.decodeUnStakeOutput(bytes)`

### Submit GP (General Proposal)

Submits a general governance proposal.

```ts

```

### Vote in proposal

Casts a vote on an active proposal.

```ts
const payload = qVAULT.buildVoteInProposalInput({
  proposalIndex: 0,
  proposalType: 1, // 1 = GP, 2 = QCP, etc.
  vote: 1,         // 1 = yes, 0 = no
})
```

**Output:** `{ returnCode: number }` — decode with `qVAULT.decodeVoteInProposalOutput(bytes)`

---


**Output:** `{ returnCode: number }` — decode with `qVAULT.decodeBuyQcapOutput(bytes)`

## Read functions (callers)

### `getData`

Returns all current governance data — stake amounts, proposal lists, and treasury info.

```ts
const result = await qVAULT.getData(live)
```

Returns a large struct covering staking totals, all proposal states, and protocol parameters.

---

### `getStakedAmountAndVotingPower`

Returns the stake and voting power for a specific identity.

```ts
const result = await qVAULT.getStakedAmountAndVotingPower(
  live,
  { voter: identity },
  { identityToPublicKey },
)
```

**Output**

| Field | Type | Description |
|---|---|---|
| `stakedAmount` | `bigint` | QCAP staked by this identity. |
| `votingPower` | `bigint` | Voting power derived from the stake. |

---

### `getGP` / `getQCP` / `getIPOP` / `getQEarnP` / `getFundP` / `getMKTP` / `getAlloP`

Returns the current state of a specific proposal type by index.

```ts
const result = await qVAULT.getGP(live, { index: 0 })
const result = await qVAULT.getQCP(live, { index: 0 })
// same pattern for all proposal types
```

Each returns the corresponding `*PInfo` struct with `proposer`, vote tallies, `proposedEpoch`, `result`, and proposal-specific fields.

---

### `getIdentitiesHvVtPw`

Returns identities that have voting power.

```ts
const result = await qVAULT.getIdentitiesHvVtPw(live)
```

---

### `ppCreationPower`

Returns the proposal creation power for the caller.

```ts
const result = await qVAULT.ppCreationPower(live, { voter: identity }, { identityToPublicKey })
```
