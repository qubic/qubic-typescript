---
title: useContractQuery
description: TanStack Query hook for calling a typed contract read function from @qubic.org/contracts.
---

`useContractQuery` runs any typed contract read function from `@qubic.org/contracts` as a TanStack Query. It automatically provides the crypto helpers (`identityToPublicKey`, `publicKeyToIdentity`) and disables the query when `input` is `null` or `undefined`.

## `useContractQuery(fn, input, options?)`

```tsx
import { useContractQuery } from "@qubic.org/react"
import { qearnGetStateOfRound } from "@qubic.org/contracts"

function QearnRoundState({ epoch }: { epoch: number }) {
  const { data, isLoading, error } = useContractQuery(
    qearnGetStateOfRound,
    { epoch },
    { refetchInterval: 30_000 },
  )

  if (isLoading) return <p>Loading...</p>
  if (error) return <p>Error: {error.message}</p>

  return <p>Total locked: {data?.totalLockedAmount?.toString()}</p>
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `fn` | `ContractQueryFn<TInput, TOutput>` | A typed caller function from `@qubic.org/contracts` (e.g. `qearnGetStateOfRound`). |
| `input` | `TInput \| null \| undefined` | Input for the contract function. Pass `null` or `undefined` to disable the query. |
| `options` | `UseQueryOptions` | Standard TanStack Query options (e.g. `refetchInterval`, `staleTime`). |

**Returns** `UseQueryResult<TOutput>` — standard TanStack Query result with `data`, `isLoading`, `error`, `refetch`.

## Disabling the query

Pass `null` or `undefined` as `input` to conditionally disable the query:

```tsx
const { data } = useContractQuery(
  qearnGetUserLockedInfo,
  account ? { user: account.identity, epoch } : null,
)
// query runs only when account is available
```
