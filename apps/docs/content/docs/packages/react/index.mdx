`@qubic.org/react` integrates the entire Qubic SDK into React 18+. Data hooks are powered by TanStack Query. Seeds never appear in React state or DevTools. Wallet connectors are pluggable.

**Peer dependency:** React 18 or later.

## Provider hierarchy

Wrap your app with providers in this order:

```tsx
<QubicProvider liveClient={live} archiveClient={archive}>
  <WalletProvider connectors={connectors}>      {/* optional */}
    <VaultProvider vaultData={vault}>           {/* optional */}
      <App />
    </VaultProvider>
  </WalletProvider>
</QubicProvider>
```

`QubicProvider` is required. `WalletProvider` and `VaultProvider` are independent — include only what your app needs.

## Key concepts

**Seeds never in React state** — `VaultProvider` stores the unlocked seed in a `useRef`. It's never in Redux, Zustand, TanStack Query's cache, or React DevTools.

**Session persistence** — when `persistSession` is enabled, the decrypted key is stored in IndexedDB with `extractable: false`. It survives page reload but cannot be read back as raw bytes.

**Pluggable connectors** — `WalletConnector` is an interface. Three built-in connectors ship with the package; you can write your own.
