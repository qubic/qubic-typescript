A `WalletConnector` is an object that implements a standard connect/disconnect/sign interface. Pass connector instances to `WalletProvider` to make them available via `useWallet` and `useWalletConnector`.

## `extensionConnector`

Connects to the Qubic browser extension via `window.qubic`. No configuration needed — import and use directly.

```tsx
import { extensionConnector, WalletProvider } from "@qubic.org/react"

<WalletProvider connectors={[extensionConnector]}>
  {children}
</WalletProvider>
```

`extensionConnector.isAvailable()` returns `false` during SSR and when the extension is not installed. Filter with `c.isAvailable()` before rendering connect buttons.

## `createWalletConnectConnector(options)`

Creates a WalletConnect v2 connector. Install `@walletconnect/sign-client` separately.

```tsx
import { createWalletConnectConnector, extensionConnector, WalletProvider } from "@qubic.org/react"
import { SignClient } from "@walletconnect/sign-client"

const wcConnector = createWalletConnectConnector({
  createClient: () =>
    SignClient.create({
      projectId: "your-walletconnect-project-id",
      metadata: {
        name: "My Qubic App",
        description: "A Qubic dApp",
        url: "https://your-app.com",
        icons: ["https://your-app.com/icon.png"],
      },
    }),
})

<WalletProvider connectors={[extensionConnector, wcConnector]}>
  {children}
</WalletProvider>
```

**Options**

| Name | Type | Description |
|---|---|---|
| `createClient` | `() => Promise<SignClient>` | Factory for the WalletConnect `SignClient`. Called lazily on the first connection attempt. |

## `createMetaMaskSnapConnector(options?)`

Creates a connector for the Qubic MetaMask Snap. MetaMask must be installed and the user approves the Snap on first use.

```tsx
import {
  createMetaMaskSnapConnector,
  extensionConnector,
  WalletProvider,
  DEFAULT_SNAP_ID,
} from "@qubic.org/react"

const snapConnector = createMetaMaskSnapConnector({
  snapId: DEFAULT_SNAP_ID, // "npm:@qubic.org/metamask-snap"
})

<WalletProvider connectors={[extensionConnector, snapConnector]}>
  {children}
</WalletProvider>
```

**Options**

| Name | Type | Default | Description |
|---|---|---|---|
| `snapId` | `string` | `DEFAULT_SNAP_ID` | Snap package identifier. Override to use a local or forked Snap. |

## All three together

```tsx
import {
  WalletProvider,
  extensionConnector,
  createWalletConnectConnector,
  createMetaMaskSnapConnector,
  DEFAULT_SNAP_ID,
} from "@qubic.org/react"
import { SignClient } from "@walletconnect/sign-client"

const connectors = [
  extensionConnector,
  createWalletConnectConnector({
    createClient: () =>
      SignClient.create({ projectId: process.env.NEXT_PUBLIC_WC_PROJECT_ID! }),
  }),
  createMetaMaskSnapConnector({ snapId: DEFAULT_SNAP_ID }),
]

export function App() {
  return (
    <WalletProvider connectors={connectors}>
      {children}
    </WalletProvider>
  )
}
```

## Custom connectors

Implement `WalletConnector` to connect any signing backend:

```ts
import type { WalletConnector } from "@qubic.org/react"

const myConnector: WalletConnector = {
  id: "my-wallet",

  isAvailable() {
    return typeof window !== "undefined" && !!window.myWallet
  },

  async connect() {
    const accounts = await window.myWallet.requestAccounts()
    return { identity: accounts[0].address }
  },

  async disconnect() {
    await window.myWallet.disconnect()
  },

  async signTransaction(txBytes) {
    return window.myWallet.signTransaction(txBytes)
  },
}
```

**`WalletConnector` interface**

| Member | Type | Description |
|---|---|---|
| `id` | `string` | Unique slug. Stored in `localStorage` to restore the last-used connector. |
| `isAvailable()` | `() => boolean` | Whether the connector works in the current environment. |
| `connect()` | `() => Promise<{ identity: Identity }>` | Open a connection and return the account. |
| `disconnect()` | `() => Promise<void>` | Close the connection. |
| `signTransaction(tx)` | `(tx: Uint8Array) => Promise<Uint8Array>` | Sign transaction bytes and return signed bytes. |
