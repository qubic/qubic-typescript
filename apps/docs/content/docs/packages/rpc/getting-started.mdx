---
title: Getting Started
description: Query the current tick and an account balance in under ten lines.
---

<Steps>
<Step>
**Create a live client**

`createLiveClient` connects to `https://rpc.qubic.org` by default. No configuration is required.

```ts
import { createLiveClient } from "@qubic.org/rpc"

const live = createLiveClient()
```
</Step>
<Step>
**Query tick info and a balance**

```ts
import { createLiveClient } from "@qubic.org/rpc"
import { toIdentity } from "@qubic.org/types"

const live = createLiveClient()

const tickResult = await live.getTickInfo()
if (!tickResult.ok) throw tickResult.error
const { tick, epoch } = tickResult.value
console.log(`Epoch ${epoch}, tick ${tick}`)

const identity = toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL")
const balanceResult = await live.getBalance(identity)
if (!balanceResult.ok) throw balanceResult.error
console.log(`Balance: ${balanceResult.value.balance} QU`)
```
</Step>
<Step>
**Look up a historical transaction**

Switch to `createQueryClient` for archive data.

```ts
import { createQueryClient } from "@qubic.org/rpc"

const archive = createQueryClient()

const txResult = await archive.getTransactionByHash("abcdef1234...")
if (!txResult.ok) throw txResult.error
console.log(`${txResult.value.sourceId} → ${txResult.value.destId}: ${txResult.value.amount} QU`)
```
</Step>
</Steps>
