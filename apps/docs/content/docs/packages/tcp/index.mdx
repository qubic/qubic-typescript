`@qubic.org/tcp` lets you talk directly to Qubic peer nodes over TCP. Use it when you need the lowest possible latency, when the HTTP gateway is unavailable, or when building node monitoring tooling.

<Callout>
  For most applications, [`@qubic.org/rpc`](/docs/packages/rpc) is simpler and requires no TCP connection management. Reach for `@qubic.org/tcp` when you specifically need peer-level access.
</Callout>

## Frame format

Every Qubic TCP message uses an 8-byte frame header:

```
[size: 3 bytes LE][type: 1 byte][dejavu: 4 bytes LE][payload: N bytes]
```

`size` is the total message length including the 8-byte header. `dejavu` is a random nonce echoed in the response to pair requests and responses.

## Quick start

```ts
import { createNodePool, requestCurrentTickInfo, requestEntity } from "@qubic.org/tcp"
import { identityToPublicKey } from "@qubic.org/crypto"
import { toIdentity } from "@qubic.org/types"

const pool = createNodePool(["node1.qubic.org", "node2.qubic.org"])

try {
  const { tick, epoch } = await requestCurrentTickInfo(pool)
  console.log(`Epoch ${epoch}, tick ${tick}`)

  const pk = identityToPublicKey(toIdentity("CFBMEMZOI..."))
  const { entity } = await requestEntity(pool, pk)
  console.log("Balance:", entity.incomingAmount - entity.outgoingAmount)
} finally {
  pool.close()
}
```
