`@qubic.org/registry` stores per-epoch snapshots of every deployed Qubic smart contract's binary interface. The codec engine lets you encode inputs and decode outputs for any contract at any epoch — including historical transactions.

## Concepts

### Epoch versioning

An ABI version is valid for a range of epochs. `effectiveFromEpoch` marks when it became active. `effectiveToEpoch: null` means the ABI is still current.

`getAbi(registry, contractIndex, epoch)` finds the version whose range covers the requested epoch.

### Static import vs registry client

Two ways to access the registry:

- **Static import** — ships with the package, no network required. Best for production apps that only need current ABIs.
- **Registry client** (`createRegistryClient()`) — fetches from a remote API. Useful when you need historical lookups from a browser without bundling the full registry JSON.

## Quick start

```ts
import { getAbi, getProcedure, buildPayload, decodePayload } from "@qubic.org/registry"
import { identityToPublicKey, publicKeyToIdentity } from "@qubic.org/crypto"
import registry from "@qubic.org/registry/registry.json"
import type { ContractRegistry } from "@qubic.org/registry"

const reg = registry as ContractRegistry

const { version } = getAbi(reg, 9, 212) // Qearn at epoch 212
const proc = getProcedure(version, 6)   // lock_input procedure

const payload = buildPayload(
  proc.inputFields,
  version.structs ?? {},
  { amount: 10_000_000n },
  identityToPublicKey,
)
```
