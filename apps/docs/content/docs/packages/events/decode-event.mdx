## `decodeEvent(bobLogEvent)`

Parses the binary `data` field of a raw log event and returns a typed discriminated union keyed on `logType`.

```ts
import { decodeEvent, LOG_TYPE } from "@qubic.org/events"

const typed = decodeEvent(rawEvent)

if (typed.logType === LOG_TYPE.QU_TRANSFER) {
  const { source, destination, amount } = typed.data
  console.log(`${source} → ${destination}: ${amount}n QU`)
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `bobLogEvent` | `BobLogEvent` | Raw log event from `bob.subscribe("eventLogs", ...)`. |

**Returns** `TypedEvent` — a discriminated union with `logType` and `data` fields matching the event type.

**Throws** `EventDecodeError` — if the payload is malformed or too short. Wrap in `try/catch` in subscription loops.

---

## `TypedEvent` shape

Every `TypedEvent` has this structure:

```ts
type TypedEvent = {
  logType: number
  tick: number
  txId: string
  data: EventData  // specific to the logType
}
```

Switch on `logType` to narrow `data` to the correct type.

---

## Event data by log type

### `QU_TRANSFER` (0)

```ts
typed.data.source       // Identity — sender
typed.data.destination  // Identity — recipient
typed.data.amount       // bigint — amount in QU
```

### `ASSET_ISSUANCE` (1)

```ts
typed.data.issuer              // Identity
typed.data.assetName           // string
typed.data.numberOfShares      // bigint
typed.data.unitOfMeasurement   // string
```

### `ASSET_OWNERSHIP_CHANGE` (2)

```ts
typed.data.issuer          // Identity
typed.data.assetName       // string
typed.data.owner           // Identity — previous owner
typed.data.newOwner        // Identity
typed.data.numberOfShares  // bigint
```

### `ASSET_POSSESSION_CHANGE` (3)

```ts
typed.data.issuer            // Identity
typed.data.assetName         // string
typed.data.owner             // Identity
typed.data.newPossessor      // Identity
typed.data.numberOfShares    // bigint
```

### Contract messages (4–7)

`CONTRACT_ERROR_MESSAGE`, `CONTRACT_WARNING_MESSAGE`, `CONTRACT_INFORMATION_MESSAGE`, `CONTRACT_DEBUG_MESSAGE` all have the same shape:

```ts
typed.data.contractIndex  // number
typed.data.message        // string
```

### `BURNING` (8)

```ts
typed.data.sourceId  // Identity
typed.data.amount    // bigint
```

### `DUST_BURNING` (9)

```ts
typed.data.numberOfBurns  // number
typed.data.totalAmount    // bigint
```

### `SPECTRUM_STATS` (10)

```ts
typed.data.totalAmount      // bigint
typed.data.dustThreshold    // bigint
typed.data.numberOfEntities // number
```

### `CUSTOM_MESSAGE` (255)

```ts
typed.data  // Uint8Array — contract-specific binary payload
```

Decode `CUSTOM_MESSAGE` payloads with `decodePayload` from `@qubic.org/registry`.

## Error handling

```ts
import { decodeEvent, EventDecodeError } from "@qubic.org/events"

bob.subscribe("eventLogs", identity, (events) => {
  for (const raw of events) {
    try {
      const typed = decodeEvent(raw)
      handleEvent(typed)
    } catch (e) {
      if (e instanceof EventDecodeError) {
        console.warn("Malformed event at tick", raw.tick, e.message)
      } else {
        throw e
      }
    }
  }
})
```
