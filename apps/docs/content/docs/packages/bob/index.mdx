## Introduction

`@qubic.org/bob` wraps the Bob indexer in three transport-specific clients:

| Client | Use for |
|---|---|
| `rest` | One-shot HTTP lookups such as status, balance, tick, and transaction fetches |
| `rpc` | JSON-RPC queries such as logs, transfers, balances, contract reads, and broadcasts |
| `subscription` | Long-lived WebSocket streams for ticks, logs, transfers, and tick data |

If you want all three at once, use `createBobClient()`.

## Quick start

```ts
import { createBobClient } from "@qubic.org/bob"

const bob = createBobClient({
  baseUrl: "http://localhost:40420",
  wsUrl: "ws://localhost:40420",
})

const status = await bob.rest.getStatus()
if (status.ok) {
  console.log("healthy:", status.value.healthy)
}

for await (const event of bob.subscription.subscribeNewTicks()) {
  if (event.isCatchUp) continue
  console.log(`Tick ${event.data.tick} in epoch ${event.data.epoch}`)
  break
}

bob.subscription.close()
```
