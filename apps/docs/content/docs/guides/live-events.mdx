title: Subscribe to live events
description: Stream real-time tick data and account events using @qubic.org/bob and @qubic.org/events.

`@qubic.org/bob` provides a persistent WebSocket connection to the Qubic live node. Combined with `@qubic.org/events`, you can decode typed event logs from every tick as they arrive.

## Connect and subscribe to ticks

`bob.subscription.subscribeNewTicks()` returns an `AsyncIterable` that yields tick notifications as they arrive:

```ts
import { createBobClient } from "@qubic.org/bob"

const bob = createBobClient()

for await (const event of bob.subscription.subscribeNewTicks()) {
  console.log(`Tick ${event.data.tick} — epoch ${event.data.epoch}`)
}
```

Pass an `AbortSignal` to stop the subscription:

```ts
const controller = new AbortController()

for await (const event of bob.subscription.subscribeNewTicks({ signal: controller.signal })) {
  console.log(`Tick ${event.data.tick}`)
  if (someCondition) controller.abort()
}
```

## Subscribe to log events

`subscribeLogs` streams all log events. Pass a `BobLogFilter` to narrow the results:

```ts
import { toIdentity } from "@qubic.org/types"

const identity = toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL")

for await (const event of bob.subscription.subscribeLogs({ identity })) {
  console.log("Log type:", event.data.logType, "data:", event.data.data)
}
```

Each `event` has a `data` field (a `BobLogEvent` with `tick`, `logType`, `data`, etc.) and an `isCatchUp` flag.

## Decode event data with @qubic.org/events

The `data` field on each log event is raw base64. Use `decodeEvent` to parse it into typed objects:

```ts
import { decodeEvent, LOG_TYPE } from "@qubic.org/events"

for await (const event of bob.subscription.subscribeLogs({ identity })) {
  const decoded = decodeEvent(event.data)

  switch (decoded.logType) {
    case LOG_TYPE.QU_TRANSFER:
      console.log("Transfer:", decoded.data.source, "→", decoded.data.destination, decoded.data.amount)
      break
    case LOG_TYPE.ASSET_ISSUANCE:
      console.log("Asset issuance:", decoded.data)
      break
  }
}
```

`decodeEvent` takes a single `RawQubicLogEvent` argument (`{ tick, logType, data }`). `BobLogEvent` from bob is structurally compatible. The function throws `EventDecodeError` for unknown log types.

See [`@qubic.org/events`](/packages/events) for all event type constants and their data shapes.

## Filter events

Use `eventFilter()` to build a filter object. Pass its `toBobFilter()` result to `subscribeLogs`:

```ts
import { eventFilter, LOG_TYPE } from "@qubic.org/events"

const filter = eventFilter()
  .ofTypes(LOG_TYPE.QU_TRANSFER)
  .build()

const bobFilter = filter.toBobFilter()

for await (const event of bob.subscription.subscribeLogs(bobFilter)) {
  console.log("Transfer:", event.data.data)
}
```

Chain multiple conditions:

```ts
const filter = eventFilter()
  .ofTypes(LOG_TYPE.QU_TRANSFER)
  .forIdentity(identity)
  .build()
```

## Automatic reconnect

bob reconnects automatically on disconnection. The subscription resumes from the last received `logId`, replaying any missed events with `isCatchUp: true`:

```ts
for await (const event of bob.subscription.subscribeLogs()) {
  if (event.isCatchUp) {
    console.log("Catch-up log:", event.data.tick)
  } else {
    console.log("Live log:", event.data.tick)
  }
}
```

## Complete example

```ts title="live-events.ts"
import { createBobClient } from "@qubic.org/bob"
import { decodeEvent, eventFilter, LOG_TYPE } from "@qubic.org/events"
import { toIdentity } from "@qubic.org/types"

const bob = createBobClient()

const identity = toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL")
const transferFilter = eventFilter().ofTypes(LOG_TYPE.QU_TRANSFER).build().toBobFilter()

// Stream ticks in the background
;(async () => {
  for await (const event of bob.subscription.subscribeNewTicks()) {
    console.log(`Tick ${event.data.tick} (epoch ${event.data.epoch})`)
  }
})()

// Stream transfers for our identity
for await (const event of bob.subscription.subscribeLogs({ ...transferFilter, identity })) {
  const decoded = decodeEvent(event.data)
  console.log("Transfer:", decoded.data)
}
```

Run:

```bash
bun live-events.ts
```
