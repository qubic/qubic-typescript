---
title: useWalletConnector
description: Manage connection state for one specific wallet connector.
---

`useWalletConnector(connector)` manages the lifecycle for a single connector instance, without requiring `WalletProvider`. Use it when you only need one backend such as the browser extension.

## `useWalletConnector(connector)`

```tsx
import { extensionConnector, useWalletConnector } from "@qubic.org/react"

function ConnectButton() {
  const { isAvailable, isConnected, isConnecting, account, connect, disconnect, error } =
    useWalletConnector(extensionConnector)

  if (!isAvailable) return <p>Install the Qubic extension.</p>

  if (!isConnected) {
    return (
      <button onClick={() => connect()} disabled={isConnecting}>
        {isConnecting ? "Connecting…" : "Connect"}
      </button>
    )
  }

  return (
    <div>
      <p>{account?.name ?? account?.identity}</p>
      <button onClick={disconnect}>Disconnect</button>
      {error && <p>{error.message}</p>}
    </div>
  )
}
```

**Returns**

| Field | Type | Description |
|---|---|---|
| `isAvailable` | `boolean` | Whether the connector backend is present in this environment. |
| `isConnected` | `boolean` | True when an account is connected. |
| `isConnecting` | `boolean` | True while `connect()` is in progress. |
| `account` | `WalletAccount \| null` | Connected account or `null`. |
| `error` | `Error \| undefined` | Error from the last connect/disconnect attempt. |
| `connect` | `(options?) => Promise<void>` | Connect the selected backend. |
| `disconnect` | `() => Promise<void>` | Disconnect the active session. |
| `sendTransaction` | `(tx) => Promise<SendTransactionResult>` | Ask the connector to sign and send a transaction request. |
| `signTransaction` | `(tx) => Promise<SignTransactionResult>` | Ask the connector to sign a transaction request without broadcasting. |
| `signMessage` | `(message: string) => Promise<SignMessageResult>` | Sign an arbitrary message string. |

For a multi-connector app-wide context, use `WalletProvider` + `useWallet()` instead.
