`@qubic.org/types` has no runtime dependencies. It exports the branded types, constants, and error classes shared across the entire SDK.

## What's in this package

**Branded types** — `Identity`, `Seed`, `TxHash`, `Base64` with phantom type brands for compile-time safety.

**Constructors and guards** — `toIdentity`, `isIdentity`, `toSeed`, `isSeed`, `toTxHash`, `isTxHash` for safe parsing.

**Protocol constants** — `PROTOCOL`, `CONTRACT_INDEX`, `LOG_TYPE`.

**Error classes** — `QubicError`, `InvalidIdentityError`, `InvalidSeedError`, `InvalidTxHashError`.
