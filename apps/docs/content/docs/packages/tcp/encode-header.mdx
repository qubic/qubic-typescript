---
title: encodeHeader
description: Builds an 8-byte Qubic TCP frame header from message type, payload size, and an optional dejavu nonce.
---

## Signature

```ts
encodeHeader(type: number, payloadSize: number, dejavu?: number): Uint8Array
```

## Purpose

Encodes an 8-byte frame header for a Qubic TCP message. Every Qubic TCP message uses this header format:

```
[size: 3 bytes LE][type: 1 byte][dejavu: 4 bytes LE][payload: N bytes]
```

The `size` field written to the header is `HEADER_SIZE + payloadSize` — the function adds `HEADER_SIZE` (8) internally.

```ts
import { encodeHeader, MESSAGE_TYPE } from "@qubic.org/tcp"

const payload = new Uint8Array(32)
const header = encodeHeader(MESSAGE_TYPE.BROADCAST_TRANSACTION, payload.length)
// Returns Uint8Array of length 8
```

## Parameters

| Name | Type | Description |
|---|---|---|
| `type` | `number` | Message type constant (see `MESSAGE_TYPE`) |
| `payloadSize` | `number` | Byte length of the payload (not the total message size) |
| `dejavu` | `number` | Optional 32-bit nonce echoed in responses to pair request/response. Auto-generated if omitted. |

## Returns

`Uint8Array` — exactly 8 bytes.

## Frame format reference

| Field | Size | Description |
|---|---|---|
| `size` | 3 bytes LE | Total message length including the 8-byte header |
| `type` | 1 byte | Message type constant |
| `dejavu` | 4 bytes LE | Random nonce |

## Custom request example

```ts
import {
  createNodeConnection,
  encodeHeader,
  decodeCurrentTickInfo,
  MESSAGE_TYPE,
} from "@qubic.org/tcp"

const conn = await createNodeConnection("node1.qubic.org")

const header = encodeHeader(MESSAGE_TYPE.REQUEST_CURRENT_TICK_INFO, 0)

const packets = await conn.request(MESSAGE_TYPE.REQUEST_CURRENT_TICK_INFO)
const info = decodeCurrentTickInfo(packets[0])

console.log("Tick:", info.tick)
conn.close()
```
