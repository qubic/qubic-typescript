## Introduction

### Wallet

A `Wallet` holds a single seed and exposes methods to build, sign, and encode transactions in one call. It abstracts the `buildTransaction` → `signTransaction` → `encodeTransaction` pipeline from `@qubic.org/tx`.

```ts
import { createWallet, generateSeed } from "@qubic.org/wallet"

const wallet = createWallet(generateSeed())
wallet.identity   // the Identity derived from the seed
wallet.publicKey  // the 32-byte public key
```

### Vault

A `Vault` stores multiple labeled seeds, encrypted with a user password using AES-256-GCM + PBKDF2. Seeds never leave the vault in plain form — you export only the encrypted blob and decrypt at runtime with the password.

```ts
const vault = await createVault("my-password")
await vault.addSeed("main", seed)
const walletFromVault = createWalletFromVault(vault, "main")
```

### When to use this vs `@qubic.org/tx`

`@qubic.org/wallet` is the right choice for applications — it handles the full transaction lifecycle and key management. Use `@qubic.org/tx` directly only if you need raw binary control, custom signing flows, or hardware wallet integration.

## Examples

### Send a QU transfer

```ts
import { createWallet, generateSeed } from "@qubic.org/wallet"
import { createLiveClient } from "@qubic.org/rpc"
import { contractIndexToIdentity } from "@qubic.org/crypto"

const live   = createLiveClient()
const wallet = createWallet(generateSeed())
const tickResult = await live.getTickInfo()
if (!tickResult.ok) throw tickResult.error
const { tick } = tickResult.value

const { encoded, hash } = await wallet.buildTransaction({
  destination: toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL"),
  amount: 1_000_000n,
  targetTick: tick + 5,
  currentTick: tick,
})

const result = await live.broadcastTransaction(encoded)
if (!result.ok) throw result.error
console.log(`TX ${hash} broadcast to ${result.value.peersBroadcastedTo} peers`)
```

### Store seeds in an encrypted vault

```ts
import { createVault, addToVault, exportVault, importVault, unlockVault, createWallet } from "@qubic.org/wallet"
import { generateSeed } from "@qubic.org/wallet"

// Create a vault with an initial seed
const seed = generateSeed()
const vaultData = await createVault("my-strong-password", [seed])

// Add more seeds later — returns new VaultData (immutable)
const updatedVault = await addToVault(vaultData, "my-strong-password", generateSeed())

// Export to a portable encrypted blob (store in localStorage, a file, etc.)
const blob = exportVault(updatedVault)

// Later: restore and unlock
const restored = importVault(blob)
const seeds = await unlockVault(restored, "my-strong-password")
const wallet = createWallet(seeds[0])
console.log("Wallet identity:", wallet.identity)
```

### Call a smart contract

```ts
import { createWallet, generateSeed } from "@qubic.org/wallet"
import { qearn } from "@qubic.org/contracts"
import { createLiveClient } from "@qubic.org/rpc"
import { contractIndexToIdentity } from "@qubic.org/crypto"

const live   = createLiveClient()
const wallet = createWallet(generateSeed())
const tickResult = await live.getTickInfo()
if (!tickResult.ok) throw tickResult.error
const { tick } = tickResult.value

const payload     = qearn.buildLockInput({ amount: 10_000_000n })
const destination = contractIndexToIdentity(qearn.contractIndex)

const { encoded, hash } = await wallet.buildContractCall({
  destination,
  amount: 10_000_000n,
  targetTick: tick + 5,
  currentTick: tick,
  inputType: qearn.LOCK_INPUT_TYPE,
  payload,
})

await live.broadcastTransaction(encoded)
console.log("SC TX hash:", hash)
```
