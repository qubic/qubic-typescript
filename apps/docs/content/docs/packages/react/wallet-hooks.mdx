## `useWallet()`

Returns the current wallet connection state and all connection actions. Requires `WalletProvider` as an ancestor.

```tsx
import { useWallet } from "@qubic.org/react"

function WalletStatus() {
  const {
    connectors,
    isConnected,
    isConnecting,
    account,
    activeConnector,
    connect,
    disconnect,
    error,
  } = useWallet()

  if (!isConnected) {
    return (
      <>
        {connectors.filter((c) => c.isAvailable()).map((c) => (
          <button key={c.id} type="button" onClick={() => connect(c.id)} disabled={isConnecting}>
            {isConnecting ? "Connecting…" : `Connect via ${c.id}`}
          </button>
        ))}
        {error && <p className="text-red-600">{error.message}</p>}
      </>
    )
  }

  return (
    <div>
      <p>Connected: {account?.identity}</p>
      <p>Via: {activeConnector?.id}</p>
      <button type="button" onClick={disconnect}>Disconnect</button>
    </div>
  )
}
```

### Return shape

| Field | Type | Description |
|---|---|---|
| `connectors` | `WalletConnector[]` | All connectors passed to `WalletProvider`. |
| `isConnected` | `boolean` | Whether a connector is currently connected. |
| `isConnecting` | `boolean` | Whether a connection attempt is in progress. |
| `account` | `{ identity: Identity } \| null` | The connected account, or `null` if not connected. |
| `activeConnector` | `WalletConnector \| null` | The connector that is currently active. |
| `connect` | `(connectorId: string) => Promise<void>` | Connect to a connector by its `id`. |
| `disconnect` | `() => void` | Disconnect the active connector. |
| `error` | `Error \| null` | Last connection error, if any. |

### Filtering available connectors

`c.isAvailable()` returns `false` during SSR and for connectors whose required extension or library is absent. Always filter before rendering connect buttons:

```tsx
const available = connectors.filter((c) => c.isAvailable())
```

## `useWalletConnector(connector)`

Use a specific connector directly without `WalletProvider`. Useful when you need raw connector access for a custom wallet UI or when `WalletProvider` overhead isn't needed.

```tsx
import { useWalletConnector, extensionConnector } from "@qubic.org/react"

function HeadlessWallet() {
  const { connect, disconnect, account, isConnected } = useWalletConnector(extensionConnector)

  return isConnected
    ? <button type="button" onClick={disconnect}>Disconnect {account?.identity}</button>
    : <button type="button" onClick={connect}>Connect extension</button>
}
```

### When to use `useWalletConnector` vs `useWallet`

| Scenario | Hook to use |
|---|---|
| App with multiple connector choices | `useWallet` with `WalletProvider` |
| Single known connector, no switcher UI | `useWalletConnector` |
| Embedding connector logic in a library | `useWalletConnector` |
| Auto-reconnect on load | `useWallet` (persists via `storageKey`) |

## `useVaultState()`

Returns the current vault lock state and methods to lock/unlock it. Requires `VaultProvider` as an ancestor.

```tsx
import { useVaultState } from "@qubic.org/react"

function VaultControl() {
  const { isUnlocked, identities, isUnlocking, error, unlock, lock } = useVaultState()

  if (!isUnlocked) {
    return (
      <form onSubmit={(e) => {
        e.preventDefault()
        const pw = (e.currentTarget.elements.namedItem("pw") as HTMLInputElement).value
        unlock(pw)
      }}>
        <input name="pw" type="password" placeholder="Password" />
        <button type="submit" disabled={isUnlocking}>
          {isUnlocking ? "Unlocking…" : "Unlock"}
        </button>
        {error && <p>{error.message}</p>}
      </form>
    )
  }

  return (
    <>
      {identities.map((id) => <p key={id}>{id}</p>)}
      <button type="button" onClick={lock}>Lock vault</button>
    </>
  )
}
```

### Return shape

| Field | Type | Description |
|---|---|---|
| `isUnlocked` | `boolean` | Whether the vault is currently unlocked. |
| `identities` | `Identity[]` | Identities available in the unlocked vault. |
| `isUnlocking` | `boolean` | Whether an unlock attempt is in progress. |
| `error` | `Error \| null` | Last unlock error (wrong password, corrupt data, etc.). |
| `unlock` | `(password: string) => Promise<void>` | Decrypt the vault with the given password. |
| `lock` | `() => void` | Lock the vault and clear the in-memory key. |
