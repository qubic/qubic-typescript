title: Codec
description: buildPayload, decodePayload — binary encoding and decoding of contract inputs and outputs.
---

The codec engine encodes JavaScript objects into binary payloads and decodes binary responses back into typed objects, following the field layout defined in the ABI.

---

## `buildPayload(fields, structs, input, identityToPublicKey)`

Encodes a structured input object into binary using the field layout from the ABI.

```ts
import { getAbi, getProcedure, buildPayload } from "@qubic.org/registry"
import { identityToPublicKey } from "@qubic.org/crypto"
import registry from "@qubic.org/registry/registry.json"
import type { ContractRegistry } from "@qubic.org/registry"

const reg = registry as ContractRegistry
const { version } = getAbi(reg, 9, 212) // Qearn at epoch 212
const proc = getProcedure(version, 6)   // lock_input

const payload = buildPayload(
  proc.inputFields,
  version.structs ?? {},
  { amount: 10_000_000n },
  identityToPublicKey,
)
// Returns Uint8Array — pass to wallet.buildScTransaction as inputPayload
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `fields` | `BinaryField[]` | Field definitions from `procedure.inputFields` or `fn.inputFields`. |
| `structs` | `Record<string, NamedStruct>` | Named structs from `version.structs`. Pass `{}` if unused. |
| `input` | `Record<string, unknown>` | Input object with keys matching the field names. |
| `identityToPublicKey` | `(id: Identity) => Uint8Array` | From `@qubic.org/crypto`. Used to encode `id`-type fields. |

**Returns** `Uint8Array`

**Throws** `PayloadBuildError` — on type mismatch, missing required fields, or overflow.

---

## `decodePayload(data, fields, structs, publicKeyToIdentity)`

Decodes binary payload bytes into a typed object.

```ts
import { decodePayload } from "@qubic.org/registry"
import { publicKeyToIdentity } from "@qubic.org/crypto"

const output = decodePayload(
  responseBytes,
  proc.outputFields,
  version.structs ?? {},
  publicKeyToIdentity,
)
// Returns Record<string, unknown> with field names as keys
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `data` | `Uint8Array` | Raw response bytes from the node or archive. |
| `fields` | `BinaryField[]` | Field definitions from `procedure.outputFields` or `fn.outputFields`. |
| `structs` | `Record<string, NamedStruct>` | Named structs from `version.structs`. |
| `publicKeyToIdentity` | `(pk: Uint8Array) => Identity` | From `@qubic.org/crypto`. Used to decode `id`-type fields. |

**Returns** `Record<string, unknown>`

---

## Injected converters

`buildPayload` and `decodePayload` accept `identityToPublicKey` and `publicKeyToIdentity` as parameters rather than importing `@qubic.org/crypto` directly. This keeps `@qubic.org/registry` tree-shakeable for server-side registry browsing that doesn't need the crypto library.

```ts
import { identityToPublicKey, publicKeyToIdentity } from "@qubic.org/crypto"

buildPayload(fields, structs, input, identityToPublicKey)
decodePayload(bytes, fields, structs, publicKeyToIdentity)
```

## Complete encode/decode round-trip

```ts title="codec-roundtrip.ts"
import { getAbi, getProcedure, getFunction, buildPayload, decodePayload } from "@qubic.org/registry"
import { identityToPublicKey, publicKeyToIdentity } from "@qubic.org/crypto"
import { createLiveClient } from "@qubic.org/rpc"
import registry from "@qubic.org/registry/registry.json"
import type { ContractRegistry } from "@qubic.org/registry"

const reg = registry as ContractRegistry
const live = createLiveClient()

// Get Qearn read function: getStateOfRound (inputType 1)
const { version } = getAbi(reg, 9, 212)
const fn = getFunction(version, 1)

// Encode the input
const inputPayload = buildPayload(
  fn.inputFields,
  version.structs ?? {},
  { epoch: 212 },
  identityToPublicKey,
)

// Call the contract
const response = await live.querySmartContract({
  contractIndex: 9,
  inputType: fn.inputType,
  inputSize: inputPayload.length,
  requestData: Buffer.from(inputPayload).toString("base64"),
})

// Decode the output
const result = decodePayload(
  response.responseData,
  fn.outputFields,
  version.structs ?? {},
  publicKeyToIdentity,
)

console.log("getStateOfRound result:", result)
```

<Callout>
  For most use cases, the generated wrappers in `@qubic.org/contracts` handle encoding and decoding automatically. Use the codec directly only when working with historical ABIs or contracts not yet in the generated package.
</Callout>
