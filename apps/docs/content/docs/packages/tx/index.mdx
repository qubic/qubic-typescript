`@qubic.org/tx` handles the full transaction lifecycle at the binary level: header serialization, SchnorrQ signing, base64 encoding for broadcast, and hash computation.

Most apps should use [`@qubic.org/wallet`](/docs/packages/wallet) — it wraps this package with a friendlier API. Use `@qubic.org/tx` directly when you need fine-grained control or are building tooling.

## Transaction anatomy

```
[  header: 80 bytes  ][  payload: 0–1024 bytes  ][  signature: 64 bytes  ]
```

The 80-byte header encodes source key, destination, amount, target tick, input type, and payload size.

## Three forms of a transaction

| Form | Produced by | Contents |
|---|---|---|
| **Unsigned bytes** | `buildTransaction` | Header + payload, no signature |
| **Signed bytes** | `signTransaction` | Header + payload + 64-byte SchnorrQ signature |
| **Encoded** | `encodeTransaction` | Base64 string, ready for `broadcastTransaction` |
