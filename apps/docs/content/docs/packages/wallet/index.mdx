`@qubic.org/wallet` is the recommended signing layer for most applications. It wraps `@qubic.org/tx` and `@qubic.org/crypto` with a friendlier API and adds an encrypted vault for secure seed storage.

## `createWallet(seed)`

Creates a wallet from a seed. The wallet derives the public key and identity from the seed and exposes methods for building and signing transactions.

```ts
import { createWallet, generateSeed } from "@qubic.org/wallet"

const wallet = createWallet(generateSeed())
console.log(wallet.identity) // 60-char uppercase Identity
```

`generateSeed()` produces a cryptographically random 55-character lowercase seed.
