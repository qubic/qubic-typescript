---
title: useSendContractCall
description: Mutation hook for calling a smart contract procedure.
---

TanStack `useMutation` wrapper that signs and broadcasts a smart contract procedure call. Returns standard mutation state alongside `mutate` and `mutateAsync`.

Requires either `VaultProvider` or `WalletProvider` as an ancestor.

## Signature

```ts
function useSendContractCall(): {
  mutate(params: {
    from: Identity
    inputType: number
    payload: Uint8Array
    amount?: bigint
    destination?: Identity
    tickOffset?: number
  }): void
  mutateAsync(params: {
    from: Identity
    inputType: number
    payload: Uint8Array
    amount?: bigint
    destination?: Identity
    tickOffset?: number
  }): Promise<BroadcastTransactionResponse>
  isPending: boolean
  isSuccess: boolean
  isError: boolean
  error: QubicRpcError | null
  reset(): void
}
```

## Usage

```tsx
import { useSendContractCall, useWallet } from "@qubic.org/react"
import { QEARN_LOCK_INPUT_TYPE } from "@qubic.org/contracts"

function LockButton() {
  const { account } = useWallet()
  const { mutate, isPending } = useSendContractCall()

  function handleLock() {
    mutate({
      from: account!.identity,
      inputType: QEARN_LOCK_INPUT_TYPE,
      payload: new Uint8Array(0),  // lock has no input fields
      amount: 10_000_000n,
    })
  }

  return (
    <button type="button" onClick={handleLock} disabled={isPending || !account}>
      {isPending ? "Locking…" : "Lock 10 MQUSD"}
    </button>
  )
}
```

## Input

| Field | Type | Description |
|---|---|---|
| `from` | `Identity` | The calling identity. |
| `inputType` | `number` | The procedure's input type constant (e.g. `QEARN_LOCK_INPUT_TYPE`). |
| `payload` | `Uint8Array` | Encoded procedure payload. Use an empty `Uint8Array` for procedures with no input fields. |
| `amount` | `bigint` | QU to attach to the call. Defaults to `0n`. |
| `destination` | `Identity` | Optional. Override the contract destination identity. Defaults to the all-zero SC address. |
| `tickOffset` | `number` | Optional. Added to the current tick to derive `targetTick`. Default: `5`. |

## Handling results

```tsx
const { mutate, isSuccess, isError, error, reset } = useSendContractCall()

mutate(input, {
  onSuccess: (result) => {
    console.log("Peers:", result.peersBroadcastedTo)
  },
  onError: (err) => {
    console.error("Call failed:", err.message)
  },
})
```

Call `reset()` to clear `isSuccess` / `isError` state after displaying feedback.
