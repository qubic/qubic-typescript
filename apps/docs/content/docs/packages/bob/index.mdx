`@qubic.org/bob` maintains a persistent WebSocket connection to the Qubic live node and streams tick data and account event logs in real time.

## Key concepts

**Subscriptions** — call `bob.subscribe(topic, handler)` to receive a callback each time new data arrives. The call returns an unsubscribe function.

**Auto-reconnect** — bob reconnects automatically on disconnect. Pass `autoResubscribe: true` to restore all active subscriptions after each reconnect.

**Catch-up buffer** — after reconnecting, bob may deliver buffered ticks that arrived during the gap. The `isCatchUp` flag in the callback metadata distinguishes buffered from live delivery.
