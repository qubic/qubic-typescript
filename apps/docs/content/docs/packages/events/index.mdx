`@qubic.org/events` turns raw Bob log events (base64 blobs with a type number) into fully typed TypeScript objects. It also provides a fluent filter builder and subscription helpers.

<Tabs items={["Bun", "npm", "pnpm"]}>

</Tab>
<Tab value="npm">

</Tab>

</Tab>

## Log types

| ID | Name | Data fields |
|---|---|---|
| `0` | `QU_TRANSFER` | `source`, `destination`, `amount` |
| `1` | `ASSET_ISSUANCE` | `issuer`, `assetName`, `numberOfShares`, `unitOfMeasurement` |
| `2` | `ASSET_OWNERSHIP_CHANGE` | `issuer`, `assetName`, `owner`, `newOwner`, `numberOfShares` |
| `3` | `ASSET_POSSESSION_CHANGE` | `issuer`, `assetName`, `owner`, `newPossessor`, `numberOfShares` |
| `4` | `CONTRACT_ERROR_MESSAGE` | `contractIndex`, `message` |
| `5` | `CONTRACT_WARNING_MESSAGE` | `contractIndex`, `message` |
| `6` | `CONTRACT_INFORMATION_MESSAGE` | `contractIndex`, `message` |
| `7` | `CONTRACT_DEBUG_MESSAGE` | `contractIndex`, `message` |
| `8` | `BURNING` | `sourceId`, `amount` |
| `9` | `DUST_BURNING` | `numberOfBurns`, `totalAmount` |
| `10` | `SPECTRUM_STATS` | `totalAmount`, `dustThreshold`, `numberOfEntities` |
| `11` | `ASSET_OWNERSHIP_MANAGING_CONTRACT_CHANGE` | `issuer`, `assetName`, `managingContract` |
| `12` | `ASSET_POSSESSION_MANAGING_CONTRACT_CHANGE` | `issuer`, `assetName`, `managingContract` |
| `13` | `CONTRACT_RESERVE_DEDUCTION` | `contractIndex`, `amount` |
| `14` | `ORACLE_QUERY_STATUS_CHANGE` | `oracleId`, `status` |
| `15` | `ORACLE_SUBSCRIBER_LOG_MESSAGE` | `subscriberId`, `message` |
| `255` | `CUSTOM_MESSAGE` | `Uint8Array` (contract-specific) |

## Quick start

```ts
import { createBobClient } from "@qubic.org/bob"
import { decodeEvent, eventFilter } from "@qubic.org/events"
import { toIdentity } from "@qubic.org/types"

const bob = createBobClient({ autoResubscribe: true })
await bob.connect()

const identity = toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL")

bob.subscribe("eventLogs", identity, (events) => {
  for (const raw of events) {
    const typed = decodeEvent(raw)
    console.log(typed.logType, typed.data)
  }
})
```
