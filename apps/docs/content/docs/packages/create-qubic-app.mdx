# create-qubic-app

`@qubic.org/create-qubic-app` scaffolds starter projects for building on Qubic with JavaScript and TypeScript. Run it without arguments for an interactive picker, or pass flags for reproducible scripts.

It can generate:

- Node/Bun scripts for RPC, wallet, transfer, and contract examples
- Vite React dApps with Qubic providers, encrypted vault wiring, and wallet connectors
- Next.js app router dApps with client-safe Qubic providers, encrypted vault wiring, and wallet connectors

## Usage

Interactive mode:

```bash
bunx @qubic.org/create-qubic-app
```

When linked locally, the bin can be run directly:

```bash
create-qubic-app
```

Scriptable mode:

```bash
bunx @qubic.org/create-qubic-app my-app --template node
```

```bash
bunx @qubic.org/create-qubic-app my-dapp \
  --template vite-react \
  --connectors extension,walletconnect \
  --tooling eslint \
  --styling tailwind \
  --animation motion
```

```bash
bunx @qubic.org/create-qubic-app my-next-app \
  --template next-react \
  --connectors extension,walletconnect \
  --tooling prettier
```

## Templates

| Template | Description |
|---|---|
| `node` | Node/Bun TypeScript script with RPC, wallet, safe transfer building, and contract query examples. |
| `vite-react` | Vite React dApp with `QubicProvider`, optional `VaultProvider` wiring, `WalletProvider`, balance query, and contract query examples. |
| `next-react` | Next.js app router dApp with client-only Qubic providers, optional vault wiring, and wallet connectors. |

## Code quality tooling

All templates can generate one formatter or linter setup. Biome is the default when `--tooling` is omitted.

| Tooling | Generated files and scripts |
|---|---|
| `biome` | `biome.json`, `lint`, and `format` scripts. |
| `prettier` | `.prettierrc.json`, `.prettierignore`, `format`, and `format:check` scripts. |
| `eslint` | Template-aware `eslint.config.mjs` and `lint` script. Node uses TypeScript ESLint, Vite adds React hooks/refresh rules, and Next uses `eslint-config-next`. |
| `none` | No lint or format tooling. |

Choose one tooling option:

```bash
bunx @qubic.org/create-qubic-app my-app \
  --template vite-react \
  --tooling prettier
```

In interactive mode, choose one tooling option after choosing the template.

## Web styling and animation

Web templates can generate a plain CSS starter or a Tailwind CSS v4 starter. They also include `@solar-icons/react` for button icons and data-loading UI states by default.

| Option | Description |
|---|---|
| `--styling css` | Plain generated CSS. This is the default. |
| `--styling tailwind` | Tailwind CSS v4 with `@import "tailwindcss"` and the `@tailwindcss/postcss` plugin. |
| `--animation none` | No animation dependency. This is the default. |
| `--animation motion` | Adds Motion and wraps the main app shell with a small entry animation. |

Example:

```bash
bunx @qubic.org/create-qubic-app my-dapp \
  --template vite-react \
  --styling tailwind \
  --animation motion
```

In interactive mode, styling and animation prompts appear for Vite and Next templates.

## Wallet connectors

Web templates support extension and WalletConnect connectors. They also include optional encrypted vault wiring through `@qubic.org/wallet`:

| Connector | Description |
|---|---|
| `extension` | Qubic browser extension connector using `window.qubic`. |
| `walletconnect` | WalletConnect v2 connector. Requires a WalletConnect project ID. |
| `none` | Generate the app without wallet connectors. |

Use a comma-separated connector list:

```bash
bunx @qubic.org/create-qubic-app my-dapp \
  --template vite-react \
  --connectors extension,walletconnect
```

In interactive mode, choose one of the connector presets: wallet extension, wallet extension + WalletConnect, WalletConnect only, or no wallet connectors.

## Safety

Generated wallet and transaction examples are safe by default:

- no real seeds are included
- `.env.example` is generated instead of `.env`
- the Node transfer example does not broadcast unless you pass `--broadcast`
- frontend environment variables are only for public connector configuration
