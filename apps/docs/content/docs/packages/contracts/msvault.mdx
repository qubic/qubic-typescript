---
title: MSVault
description: Multisig vault contract — lock QU and assets behind m-of-n approval before any release.
---

MSVault (contract index `11`) holds funds in a vault that requires `m` out of `n` owner approvals before a release can go through. It supports both QUBIC (QU) and Qubic assets. Fee parameters are governed on-chain by shareholder votes.

Import the namespace:

```ts
import { msVault } from "@qubic.org/contracts"
```

---

## Procedures (write)

### Register vault

Creates a new multisig vault.

```ts
const payload = msVault.buildRegisterVaultInput(
  {
    vaultName: "MY_VAULT",          // 32-byte encoded name
    owners: [owner1, owner2, owner3], // up to 16 owner identities
    requiredApprovals: 2n,           // m-of-n threshold
  },
  identityToPublicKey,
)
```

**Input**

| Field | Type | Description |
|---|---|---|
| `vaultName` | `string` | Name encoded as a 32-byte identity-format string. |
| `owners` | `string[]` | Up to 16 owner identities. |
| `requiredApprovals` | `bigint` | Number of approvals required to release funds. |

**Output:** `{ status: bigint }` — decode with `msVault.decodeRegisterVaultOutput(bytes)`

---

### Deposit

Deposits QU into a vault. The transaction amount is the deposit amount.

```ts
const payload = msVault.buildDepositInput({ vaultId: 1n })
```

**Output:** `{ status: bigint }` — decode with `msVault.decodeDepositOutput(bytes)`

---

### Release to

Proposes (and approves if threshold is met) a release of QU to a destination.

```ts
const payload = msVault.buildReleaseToInput(
  { vaultId: 1n, amount: 1_000_000n, destination: recipientIdentity },
  identityToPublicKey,
)
```

**Input**

| Field | Type | Description |
|---|---|---|
| `vaultId` | `bigint` | Vault ID returned at registration. |
| `amount` | `bigint` | QU amount to release. |
| `destination` | `string` | Recipient identity. |

**Output:** `{ status: bigint }` — decode with `msVault.decodeReleaseToOutput(bytes)`

---

### Reset release

Cancels a pending release. Any owner can call this.

```ts
const payload = msVault.buildResetReleaseInput({ vaultId: 1n })
```

**Output:** `{ status: bigint }` — decode with `msVault.decodeResetReleaseOutput(bytes)`

---

### Deposit asset

Deposits a Qubic asset into a vault.

```ts
const payload = msVault.buildDepositAssetInput({
  vaultId: 1n,

  amount: 100n,
})
```

**Output:** `{ status: bigint }` — decode with `msVault.decodeDepositAssetOutput(bytes)`

### Reset asset release

Cancels a pending asset release.

```ts

```

**Output:** `{ status: bigint }` — decode with `msVault.decodeResetAssetReleaseOutput(bytes)`

---

### Vote fee change

Proposes new fee parameters. Takes effect when a majority of shareholders vote the same values.

```ts
const payload = msVault.buildVoteFeeChangeInput({
  newRegisteringFee: 10_000n,
  newReleaseFee: 1_000n,
  newReleaseResetFee: 500n,
  newHoldingFee: 100n,
  newDepositFee: 200n,
  burnFee: 50n,
})
```

**Output:** `{ status: bigint }` — decode with `msVault.decodeVoteFeeChangeOutput(bytes)`

---

### Revoke asset management rights

Returns asset management rights from the vault back to the caller.

```ts
const payload = msVault.buildRevokeAssetManagementRightsInput({
  asset: { issuer: issuerIdentity, assetName: assetNameEncoded },
  numberOfShares: 100n,
})
```

**Output:** `{ transferredNumberOfShares: bigint, status: bigint }` — decode with `msVault.decodeRevokeAssetManagementRightsOutput(bytes)`

## Read functions (callers)

### `getVaults`

Returns all vault IDs and names associated with an identity.

```ts
const result = await msVault.getVaults(
  live,
  { publicKey: identity },
  { identityToPublicKey },
)
```

**Output**

| Field | Type | Description |
|---|---|---|
| `numberOfVaults` | `bigint` | Number of vaults returned. |
| `vaultIds` | `bigint[]` | Vault IDs (up to 8). |
| `vaultNames` | `string[]` | Vault name strings. |

---

### `getReleaseStatus`

Returns the current pending release for a vault.

```ts
const result = await msVault.getReleaseStatus(live, { vaultId: 1n })
```

**Output**

| Field | Type | Description |
|---|---|---|
| `status` | `bigint` | Approval bitmask. Bit N is set when owner N has approved. |
| `amounts` | `bigint[]` | Requested amounts per approval. |
| `destinations` | `string[]` | Requested destinations per approval. |

---

### `getBalanceOf`

Returns the QU balance of a vault.

```ts
const result = await msVault.getBalanceOf(live, { vaultId: 1n })
```

**Output:** `{ status: bigint, balance: bigint }`

---

### `getVaultName`

```ts
const result = await msVault.getVaultName(live, { vaultId: 1n })
```

**Output:** `{ status: bigint, vaultName: string }`

---

### `getRevenueInfo`

Returns protocol-wide revenue statistics.

```ts
const result = await msVault.getRevenueInfo(live)
```

**Output**

| Field | Type | Description |
|---|---|---|

| `owners` | `string[]` | Owner identities (up to 16). |

---

### `isShareHolder`

Checks whether an identity holds shares in MSVault.

```ts

  live,
  { candidate: identity },
  { identityToPublicKey },
)
```

**Output:** `{ result: bigint }` — non-zero means yes.

## Example: register a 2-of-3 vault

```ts
import { msVault } from "@qubic.org/contracts"
import { identityToPublicKey } from "@qubic.org/crypto"
import { createLiveClient } from "@qubic.org/rpc"

const live = createLiveClient()

// Check fees before registering
const fees = await msVault.getFees(live)
if (!fees.ok) throw fees.error
console.log("Registration fee:", fees.value.registeringFee.toString())

// Build the registration payload
const payload = msVault.buildRegisterVaultInput(
  {
    vaultName: "TREASURY_VAULT_ONE_", // pad to 32 bytes as identity format
    owners: [owner1Identity, owner2Identity, owner3Identity],
    requiredApprovals: 2n,
  },
  identityToPublicKey,
)

// Submit via wallet.buildScTransaction with amount = registeringFee
```
