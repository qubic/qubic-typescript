`@qubic.org/rpc` provides two HTTP clients: one for real-time chain state and one for indexed historical data. All types are generated from the official Qubic OpenAPI schemas.

## Live vs archive

| Client | Factory | Use for |
|---|---|---|
| **Live** | `createLiveClient()` | Current tick, balances, broadcasting, contract queries |
| **Archive** | `createQueryClient()` | Historical transactions, event logs, computor lists |

## Error model

Both clients **throw** `QubicRpcError` on network failure or non-2xx responses. There is no `Result` wrapper — use `try/catch`.

```ts
try {
  const info = await live.getTickInfo()
} catch (e) {
  if (e instanceof QubicRpcError) {
    console.error(e.status, e.message)
  }
}
```
