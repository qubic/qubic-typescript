---
title: Vault
description: createVault, unlockVault, addToVault, exportVault, importVault — AES-256-GCM encrypted seed storage with PBKDF2 key derivation.
---

The vault encrypts seeds at rest using AES-256-GCM with a PBKDF2-SHA256 derived key (600,000 iterations). The result is a plain JSON object you can store anywhere — localStorage, a database, a file.

```ts
import {
  createVault, unlockVault, addToVault,
  exportVault, importVault,
} from "@qubic.org/wallet"
```

---

## `createVault(password, seeds)`

Creates a new encrypted vault from a password and one or more seeds.

```ts
import { createVault, generateSeed } from "@qubic.org/wallet"

const seed = generateSeed()
const vault = await createVault("my-strong-passphrase", [seed])
// vault: VaultData — safe to store anywhere
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `password` | `string` | The encryption passphrase. Not stored anywhere. |
| `seeds` | `Seed[]` | Seeds to encrypt. At least one required. |

**Returns** `Promise<VaultData>` — `{ version, iterations, salt, iv, ciphertext }` — all hex-encoded binary. Contains no plaintext.

---

## `unlockVault(vaultData, password)`

Decrypts the vault and returns all stored seeds.

```ts
const seeds = await unlockVault(vault, "my-strong-passphrase")
// seeds: Seed[] — one per account stored in the vault

const wallet = createWallet(seeds[0])
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `vaultData` | `VaultData` | The vault to decrypt |
| `password` | `string` | The passphrase used when `createVault` was called |

**Returns** `Promise<Seed[]>`

**Throws** `VaultDecryptionError` — if the password is wrong or the ciphertext is corrupt.

**Throws** `InvalidVaultError` — if `vaultData.version` is unsupported or the structure is malformed.

The passphrase is never stored. If lost, the vault cannot be decrypted.

---

## `addToVault(vaultData, password, seed)`

Adds a seed to an existing vault. Internally decrypts, appends the seed, then re-encrypts with a fresh IV and salt.

```ts
import { addToVault, generateSeed } from "@qubic.org/wallet"

const newSeed = generateSeed()
const updatedVault = await addToVault(vault, "my-strong-passphrase", newSeed)

// Persist the updated vault (replaces the old one)
localStorage.setItem("vault", exportVault(updatedVault))
```

**Throws** `VaultDecryptionError` — if the password is wrong.

---

## `exportVault(vaultData)` / `importVault(json)`

Serialize and deserialize a vault for storage.

```ts
// Save
const json = exportVault(vault)
localStorage.setItem("qubic-vault", json)

// Load
const loaded = importVault(localStorage.getItem("qubic-vault")!)
const seeds = await unlockVault(loaded, passphrase)
```

`exportVault` returns a JSON string. `importVault` parses it back to `VaultData` and validates the required fields.

**`importVault` throws** `InvalidVaultError` — if the JSON is malformed or missing required fields.

---

## Security properties

| Property | Detail |
|---|---|
| Encryption | AES-256-GCM with a random 12-byte IV per encryption |
| Key derivation | PBKDF2-SHA256, 600,000 iterations |
| Salt | 16 random bytes, unique per vault creation |
| Stored material | Ciphertext + IV + salt — no plaintext seed material |

The 600,000-iteration PBKDF2 makes brute-force attacks expensive. Choose a strong passphrase regardless — dictionary words are vulnerable even with high iterations.
