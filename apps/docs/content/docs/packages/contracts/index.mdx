`@qubic.org/contracts` provides ready-to-use TypeScript wrappers generated from the latest ABI snapshot in `@qubic.org/registry`. You get fully typed payload builders, output decoders, and live read callers for every deployed contract.

<Tabs items={["Bun", "npm", "pnpm"]}>
<Tab value="Bun">
```bash
bun add @qubic.org/contracts
```
</Tab>
<Tab value="npm">
```bash
npm install @qubic.org/contracts
```
</Tab>
<Tab value="pnpm">
```bash
pnpm add @qubic.org/contracts
```
</Tab>
</Tabs>

## What's inside

| Page | Description |
|---|---|
| [Namespace](./namespace) | Per-contract namespace objects — `qearn`, `qx`, `qvault`, etc. |
| [Builders](./builders) | `build{Contract}{Procedure}Input` — encode procedure inputs |
| [Decoders](./decoders) | `decode{Contract}{Procedure}Output` — decode binary responses |
| [Callers](./callers) | `{contract}{Function}` — typed live read functions |
| [callContractFunction](./call-contract-function) | Low-level primitive for calling unlisted contract functions |

## Quick start

```ts
import { qearn } from "@qubic.org/contracts"
import { createLiveClient } from "@qubic.org/rpc"
import { identityToPublicKey, publicKeyToIdentity } from "@qubic.org/crypto"

const live = createLiveClient()

// Read current round state
const result = await qearn.getStateOfRound(
  live,
  { epoch: 213 },
  { identityToPublicKey, publicKeyToIdentity },
)

if (result.ok) {
  console.log("Round state:", result.value)
}

// Build a procedure payload
const payload = qearn.buildLockInput({ amount: 10_000_000n })
```

## Error model

- **Read functions** return `Promise<Result<Output, QubicRpcError>>` — network failures are in the `Result`, not thrown.
- **Payload builders** throw `PayloadBuildError` synchronously on malformed input.
