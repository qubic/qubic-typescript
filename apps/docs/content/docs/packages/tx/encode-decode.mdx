---
title: Sign, encode & verify
description: signTransaction, encodeTransaction, decodeTransaction, computeTransactionHash, verifyTransactionSignature — the full pipeline from built transaction to broadcast.
---

After `buildTransaction` produces unsigned bytes, these functions carry the transaction through signing, encoding, hashing, and verification. The typical flow runs in sequence:

```ts
import {
  buildTransaction,
  signTransaction,
  encodeTransaction,
  computeTransactionHash,
} from "@qubic.org/tx"
import { publicKeyFromSeed } from "@qubic.org/crypto"
import { toSeed } from "@qubic.org/types"
import { createLiveClient } from "@qubic.org/rpc"

const live = createLiveClient()
const seed = toSeed(process.env.WALLET_SEED!)
const { tick } = await live.getTickInfo()

// 1. Build unsigned transaction bytes
const unsigned = buildTransaction({
  sourcePublicKey: publicKeyFromSeed(seed),
  destinationPublicKey: new Uint8Array(32), // zero bytes = contract address
  amount: 0n,
  targetTick: tick + 5,
  inputType: 0,
  inputSize: 0,
})

// 2. Sign — appends 64-byte SchnorrQ signature
const signed = await signTransaction(unsigned, seed)

// 3. Encode to base64 for the broadcast API
const encoded = encodeTransaction(signed)

// 4. Compute the canonical hash for tracking
const hash = computeTransactionHash(signed)

// 5. Broadcast
await live.broadcastTransaction(encoded)
console.log("TX hash:", hash)
```

---

## `signTransaction(txBytes, seed)`

Signs the transaction bytes with a SchnorrQ signature and appends the 64-byte signature to the end of the buffer.

```ts
import { signTransaction } from "@qubic.org/tx"

const signed: Uint8Array = await signTransaction(unsigned, seed)
// signed = unsigned (≥80 B) + signature (64 B)
```

<Callout>
  `signTransaction` is async — it calls into the WASM SchnorrQ implementation. Always `await` it.
</Callout>

**Parameters**

| Name | Type | Description |
|---|---|---|
| `txBytes` | `Uint8Array` | Unsigned transaction bytes from `buildTransaction` |
| `seed` | `Seed` | 55-character lowercase seed |

**Returns** `Promise<Uint8Array>` — header bytes + optional payload + 64-byte signature.

---

## `encodeTransaction(signedTx)`

Base64-encodes signed transaction bytes for the RPC broadcast endpoint.

```ts
import { encodeTransaction } from "@qubic.org/tx"

const encoded: Base64 = encodeTransaction(signed)
await live.broadcastTransaction(encoded)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `signedTx` | `Uint8Array` | Signed transaction bytes |

**Returns** `Base64` — standard base64 string, ready for `broadcastTransaction`.

---

## `decodeTransaction(bytes)`

Decodes raw transaction bytes back into their constituent fields. Use this to inspect a transaction without re-parsing it manually.

```ts
import { decodeTransaction } from "@qubic.org/tx"

const tx = decodeTransaction(signed)
console.log("Amount:", tx.amount)          // bigint
console.log("Target tick:", tx.targetTick) // number
console.log("Payload:", tx.payload)        // Uint8Array
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `bytes` | `Uint8Array` | Raw transaction bytes (signed or unsigned) |

**Returns** `DecodedTransaction`:

| Field | Type | Description |
|---|---|---|
| `sourcePublicKey` | `Uint8Array` | 32-byte sender public key |
| `destinationPublicKey` | `Uint8Array` | 32-byte recipient public key |
| `amount` | `bigint` | Transfer amount in QU |
| `targetTick` | `number` | Tick deadline |
| `inputType` | `number` | Procedure index (0 for plain transfers) |
| `payload` | `Uint8Array` | Remaining payload bytes |

---

## `computeTransactionHash(txBytes)`

Computes the canonical transaction hash: K12 of the transaction bytes, truncated to 32 bytes, returned as a 60-character lowercase hex `TxHash`.

```ts
import { computeTransactionHash } from "@qubic.org/tx"

const hash: TxHash = computeTransactionHash(signed)
// Use to poll the archive for confirmation
const result = await archive.getTransaction(hash)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `txBytes` | `Uint8Array` | Signed transaction bytes |

**Returns** `TxHash` — 60-character lowercase hex string.

---

## `verifyTransactionSignature(signedTx)`

Verifies the 64-byte SchnorrQ signature appended to the transaction bytes. Extracts the source public key from the transaction header and checks the signature against it.

```ts
import { verifyTransactionSignature } from "@qubic.org/tx"

const valid: boolean = await verifyTransactionSignature(signed)
// true if the signature matches the embedded source public key
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `signedTx` | `Uint8Array` | Signed transaction bytes (header + payload + 64-byte signature) |

**Returns** `Promise<boolean>` — `true` if the signature is valid.
