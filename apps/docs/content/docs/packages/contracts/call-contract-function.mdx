## `callContractFunction(options)`

The internal primitive used by all generated [callers](./callers). Call it directly only when you need to query a contract function that isn't yet in the generated package.

```ts
import { callContractFunction } from "@qubic.org/contracts"
import { createLiveClient } from "@qubic.org/rpc"

const live = createLiveClient()

const result = await callContractFunction({
  live,
  contractIndex: 9,
  inputType: 1,
  inputPayload: encodedInput,
  outputDecoder: (bytes) => decodeMyOutput(bytes),
})

if (result.ok) {
  console.log("Output:", result.value)
}
```

**Options**

| Name | Type | Description |
|---|---|---|
| `live` | `SmartContractCaller` | Any object with `querySmartContract` — typically `createLiveClient()`. |
| `contractIndex` | `number` | Contract index. |
| `inputType` | `number` | Function input type number. |
| `inputPayload` | `Uint8Array` | Optional. Encoded input bytes. Omit for functions with no input. |
| `outputDecoder` | `(bytes: Uint8Array) => T` | Decodes the raw response bytes into your output type. |

**Returns** `Promise<Result<T, QubicRpcError>>`

---

## When to use this

The generated wrappers cover all contracts in the current ABI snapshot. Use `callContractFunction` when:

- A new contract has been deployed but the package hasn't been updated yet.
- You need to call a function from a very old ABI version that no longer has a generated wrapper.
- You're building your own code generator and need the underlying primitive.

For most applications, use the generated callers directly instead.

---

## Complete example

Call a hypothetical contract index 99 function type 2, using the registry to get field definitions:

```ts title="custom-caller.ts"
import { callContractFunction } from "@qubic.org/contracts"
import { getAbi, getFunction, buildPayload, decodePayload } from "@qubic.org/registry"
import { identityToPublicKey, publicKeyToIdentity } from "@qubic.org/crypto"
import { createLiveClient } from "@qubic.org/rpc"
import registry from "@qubic.org/registry/registry.json"
import type { ContractRegistry } from "@qubic.org/registry"

const reg = registry as ContractRegistry
const live = createLiveClient()

const { version } = getAbi(reg, 99, 213)
const fn = getFunction(version, 2)

const inputPayload = buildPayload(
  fn.inputFields,
  version.structs ?? {},
  { someField: 42 },
  identityToPublicKey,
)

const result = await callContractFunction({
  live,
  contractIndex: 99,
  inputType: fn.inputType,
  inputPayload,
  outputDecoder: (bytes) =>
    decodePayload(bytes, fn.outputFields, version.structs ?? {}, publicKeyToIdentity),
})

if (result.ok) {
  console.log("Custom contract output:", result.value)
} else {
  console.error("Error:", result.error.status, result.error.message)
}
```
