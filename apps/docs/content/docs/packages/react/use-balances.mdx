---
title: useBalances
description: Fetches QU balances for multiple identities in parallel using QUtil batching.
---

`useBalances` batches balance lookups for a list of identities via the QUtil `GetBalances16` contract function (up to 16 per batch). Returns a `Map` keyed by identity, a single `error` if any batch fails, and a `refetch` function.

## `useBalances(identities)`

```tsx
import { useBalances } from "@qubic.org/react"
import { contractIndexToIdentity } from "@qubic.org/crypto"
import { QEARN_CONTRACT_INDEX } from "@qubic.org/contracts"

const WATCHED: Identity[] = [
  contractIndexToIdentity(QEARN_CONTRACT_INDEX),
  toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL"),
]

function BalanceList() {
  const { balances, isLoading, error } = useBalances(WATCHED)

  if (isLoading) return <p>Loading...</p>
  if (error) return <p>Error: {error.message}</p>

  return (
    <ul>
      {WATCHED.map((id) => (
        <li key={id}>{id}: {balances.get(id)?.toString() ?? "—"} QU</li>
      ))}
    </ul>
  )
}
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `identities` | `(Identity \| string)[] \| null \| undefined` | Identities to query. Null or empty performs no fetches. |

**Returns**

| Field | Type | Description |
|---|---|---|
| `balances` | `Map<Identity, bigint>` | Balance in QU for each successfully queried identity. |
| `isLoading` | `boolean` | True while any batch is still loading. |
| `error` | `Error \| undefined` | First error encountered across batches, or `undefined`. |
| `refetch` | `() => void` | Manually trigger a refetch of all batches. |
