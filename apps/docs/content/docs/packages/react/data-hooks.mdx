---
title: Data hooks
description: TanStack Query hooks for live node data, account balances, assets, contract reads, and archive lookups.
---

All data hooks return standard TanStack Query result objects (`data`, `isPending`, `isError`, `error`, `refetch`, etc.) and accept optional `queryOptions` overrides as the last argument.

Requires `QubicProvider` as an ancestor. Archive hooks additionally require `archiveClient` to be passed to `QubicProvider`.

---

## Live data hooks

### `useTickInfo(refetchIntervalMs?)`

Returns current tick and epoch data. Polls on an interval if `refetchIntervalMs` is provided.

```tsx
const { data, isPending } = useTickInfo(5000) // refetch every 5 s

data?.tick          // current tick number
data?.epoch         // current epoch
data?.duration      // tick duration in ms
data?.initialTick   // first tick of the epoch
```

---

### `useBalance(identity)`

Returns the QU balance for a single identity. Skips the request if `identity` is `undefined`.

```tsx
import type { Identity } from "@qubic.org/types"

const { data } = useBalance(account?.identity as Identity | undefined)

data?.balance   // bigint — balance in QU
```

---

### `useBalances(identities)`

Returns balances for multiple identities in a single call.

```tsx
const { data } = useBalances([id1, id2, id3])

// data is BalancesResult — an array keyed by identity
```

---

### `useIssuedAssets(identity)` / `useOwnedAssets(identity)` / `usePossessedAssets(identity)`

Returns the assets issued, owned, or possessed by an identity.

```tsx
const { data: issued } = useIssuedAssets(identity)
const { data: owned }  = useOwnedAssets(identity)

// data is Asset[]
```

Each `Asset` includes `assetName`, `issuerIdentity`, `numberOfUnits`, and `numberOfDecimalPlaces`.

---

### `useContractQuery(fn, input, options?)`

Wraps a contract read function from `@qubic.org/contracts` in a TanStack Query hook.

```tsx
import { qearnGetStateOfRound } from "@qubic.org/contracts"
import { useContractQuery } from "@qubic.org/react"

// Declare at module scope to keep a stable reference
const getStateOfRound = qearnGetStateOfRound

function RoundStatus({ epoch }: { epoch: number }) {
  const { data, isPending } = useContractQuery(getStateOfRound, { epoch })

  if (isPending) return <p>Loading…</p>
  return <p>Locked: {data?.lockedAmount?.toString()} QU</p>
}
```

<Callout type="warn">
  Pass the function as a stable reference (module-scope constant or `useCallback`). An inline arrow creates a new query key on every render and bypasses the cache.
</Callout>

**Parameters**

| Param | Type | Description |
|---|---|---|
| `fn` | contract read function | From `@qubic.org/contracts`. Stable reference required. |
| `input` | object | Input for the contract function. |
| `options` | `UseQueryOptions` | Standard TanStack Query options (`refetchInterval`, `enabled`, etc.). |

## Archive hooks

Require `archiveClient` on `QubicProvider`.

### `useTransaction(hash)`

Fetches a single transaction by hash.

```tsx
const { data } = useTransaction(txHash)

data?.sourceId          // sender identity
data?.destId            // recipient identity
data?.amount            // bigint
data?.tickNumber        // tick where it was included
data?.transactionStatus // "executed" | "pending" | ...
```

---

### `useEventLogs(request)`

Fetches event logs for an identity within a tick range.

```tsx
const { data } = useEventLogs({
  identity,
  startTick: 17_000_000,
  endTick:   17_001_000,
})

// data.events — raw event log array; decode with @qubic.org/events
```

---

### `useTransactionsForIdentity(request)`

Fetches the transaction history for an identity.

```tsx
const { data } = useTransactionsForIdentity({
  identity,
  startTick: 17_000_000,
  endTick:   17_001_000,
})

// data.transactions — TransactionForIdentity[]
```

---

## `useQubic()` — raw client access

Returns the RPC clients directly. Use this when you need to call a method not wrapped by a hook.

```tsx
import { useQubic } from "@qubic.org/react"

function CustomComponent() {
  const { liveClient, archiveClient } = useQubic()

  async function fetchSomething() {
    const result = await liveClient.getTickInfo()
    // ...
  }
}
```
