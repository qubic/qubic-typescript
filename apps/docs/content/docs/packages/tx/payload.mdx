---
title: Payload codec
description: buildPayload — encode typed struct fields for contract call payloads.
---

Contract calls pass a binary payload encoding the procedure's input struct. `buildPayload` is the raw tool for building these payloads field by field.

In practice, use the typed builders from `@qubic.org/contracts` (e.g. `qearn.buildUnlockInput`) instead of calling `buildPayload` directly. The contracts package generates these builders from the ABI, so they validate types and handle field ordering for you.

---

## `buildPayload(fields)`

Encodes a list of typed field values into a `Uint8Array`.

```ts
import { buildPayload } from "@qubic.org/tx"

const payload = buildPayload([
  { type: "uint64", value: 10_000_000n },
  { type: "uint32", value: 213 },
])
```

**Parameters**

`fields` is an array of `PayloadField` objects:

| `type` | JS type | Byte width | Description |
|---|---|---|---|
| `"uint8"` | `number` | 1 | Unsigned 8-bit integer |
| `"uint16"` | `number` | 2 | Unsigned 16-bit integer (LE) |
| `"uint32"` | `number` | 4 | Unsigned 32-bit integer (LE) |
| `"uint64"` | `bigint` | 8 | Unsigned 64-bit integer (LE) |
| `"sint64"` | `bigint` | 8 | Signed 64-bit integer (LE) |
| `"bytes"` | `Uint8Array` | varies | Raw bytes |
| `"id"` | `string` | 32 | Qubic identity string — encoded as its 32-byte public key via `identityToPublicKey` |

All integers are encoded little-endian, matching the Qubic wire format.

**Returns** `Uint8Array`

---

## Prefer the generated wrappers

The generated wrappers in `@qubic.org/contracts` call `buildPayload` under the hood and add input validation on top. Use the raw codec only for contract functions not yet covered by the generated wrappers.

```ts
// Prefer this (from @qubic.org/contracts):
const call = qearn.buildUnlockInput({ amount: 10_000_000n, lockedEpoch: 213 })

// Over this (raw codec):
const payload = buildPayload([
  { type: "uint64", value: 10_000_000n },
  { type: "uint32", value: 213 },
])
```

For reading binary data from contract responses, use `BinaryReader` from the same package.
