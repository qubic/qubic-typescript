`@qubic.org/tcp` lets you talk directly to Qubic peer nodes over TCP. Use it when you need the lowest possible latency, when the HTTP gateway is unavailable, or when building node monitoring tooling.

<Callout>
  For most applications, [`@qubic.org/rpc`](/docs/packages/rpc) is simpler and requires no TCP connection management. Reach for `@qubic.org/tcp` when you specifically need peer-level access.
</Callout>

## Concepts

### Frame format

Every Qubic TCP message uses an 8-byte frame header:

```
[size: 3 bytes LE][type: 1 byte][dejavu: 4 bytes LE][payload: N bytes]
```

`size` is the total message length including the 8-byte header. `dejavu` is a random nonce echoed in the response to pair requests and responses.

### Multi-packet responses

A single request can produce multiple response packets. The node sends `END_RESPONSE` (type 35) to signal the end of the response stream. If the node is temporarily busy, it sends `TRY_AGAIN` (type 36), and the client retries automatically after 1 second.

### Connection pool

`createNodePool` maintains a list of peer addresses. On connection failure or timeout it automatically moves to the next peer. Pass `AbortSignal.timeout(ms)` to bound the total wait time:

```ts
const result = await requestCurrentTickInfo(pool, {
  signal: AbortSignal.timeout(5000),
})
```

## API reference

### `createNodeConnection(host, options?)`

Opens a single TCP connection to a Qubic node.

**Parameters**

| Name | Type | Default | Description |
|---|---|---|---|
| `host` | `string` | — | Node hostname or IP. |
| `options.port` | `number` | `21841` | TCP port. |
| `options.timeoutMs` | `number` | `10000` | Connection timeout in milliseconds. |

**Returns** `Promise<NodeConnection>`

`NodeConnection` has two methods: `request(messageType, payload?)` and `close()`.

---

### `createNodePool(peers, options?)`

Creates a connection pool across multiple peer addresses.

**Parameters**

| Name | Type | Default | Description |
|---|---|---|---|
| `peers` | `string[]` | — | Array of hostnames or IPs. |
| `options.port` | `number` | `21841` | TCP port for all peers. |
| `options.timeoutMs` | `number` | `10000` | Per-connection timeout. |
| `options.maxRetries` | `number` | `peers.length` | Max retry attempts before failing. |

**Returns** `NodePool`

`NodePool` exposes the same interface as `NodeConnection` plus `pool.close()` to release all connections.

---

### `requestCurrentTickInfo(conn, options?)`

Queries the current tick and epoch from a node.

**Returns** `Promise<CurrentTickInfo>` — `{ epoch, tick, initialTick }`

```ts
import { createNodePool, requestCurrentTickInfo } from "@qubic.org/tcp"

const pool = createNodePool(["node1.qubic.org", "node2.qubic.org"])
const { epoch, tick } = await requestCurrentTickInfo(pool)
```

---

### `requestEntity(conn, publicKey, options?)`

Queries an identity's entity record (balance data) directly from a peer.

**Parameters**

| Name | Type | Description |
|---|---|---|
| `conn` | `NodeConnection \| NodePool` | Connection or pool. |
| `publicKey` | `Uint8Array` | 32-byte FourQ public key. |
| `options.signal` | `AbortSignal` | Optional abort signal. |

**Returns** `Promise<{ entity: EntityRecord, identity: Identity }>`

`EntityRecord` includes `incomingAmount`, `outgoingAmount`, `numberOfIncomingTransfers`, `numberOfOutgoingTransfers`, `latestIncomingTransferTick`, `latestOutgoingTransferTick`.

```ts
import { identityToPublicKey } from "@qubic.org/crypto"
import { toIdentity } from "@qubic.org/types"

const pk = identityToPublicKey(toIdentity("CFBMEMZOI..."))
const { entity, identity } = await requestEntity(pool, pk)
const balance = entity.incomingAmount - entity.outgoingAmount
console.log(identity, "balance:", balance, "QU")
```

---

### `broadcastTransaction(conn, txBytes, options?)`

Sends a signed transaction directly to a peer node.

**Parameters**

| Name | Type | Description |
|---|---|---|
| `conn` | `NodeConnection \| NodePool` | Connection or pool. |
| `txBytes` | `Uint8Array` | Signed transaction bytes (not base64). |

**Returns** `Promise<void>`

---

### `exchangePublicPeers(conn, options?)`

Requests the node's known peer list.

**Returns** `Promise<ExchangePublicPeers>` — `{ peers: string[] }`

---

### Frame utilities

Low-level utilities for building custom message types:

| Export | Description |
|---|---|
| `encodeHeader(size, messageType, dejavu)` | Encodes an 8-byte frame header. |
| `decodeHeader(buffer)` | Parses an 8-byte frame header. |
| `HEADER_SIZE` | `8` |
| `DEFAULT_PORT` | `21841` |
| `MESSAGE_TYPE` | Enum of known message type constants. |

---

### Decoders

For building custom request flows:

| Export | Description |
|---|---|
| `decodeCurrentTickInfo(payload)` | Parses a `CURRENT_TICK_INFO` response payload. |
| `decodeExchangePublicPeers(payload)` | Parses an `EXCHANGE_PUBLIC_PEERS` response. |
| `decodeRespondEntity(payload)` | Parses a `RESPOND_ENTITY` response payload. |

---

### Error types

| Class | When thrown |
|---|---|
| `QubicTcpError` | Base class for all TCP errors. |
| `QubicTcpConnectionError` | Could not connect to any peer. |
| `QubicTcpTimeoutError` | Request exceeded the timeout. |

## Complete example

Pool-based tick info, entity balance, and transaction broadcast:

```ts title="tcp-example.ts"
import {
  createNodePool,
  requestCurrentTickInfo,
  requestEntity,
  broadcastTransaction,
} from "@qubic.org/tcp"
import { identityToPublicKey, publicKeyFromSeed, deriveIdentityFromSeed, sign } from "@qubic.org/crypto"
import { buildTransaction, signTransaction, encodeTransaction } from "@qubic.org/tx"
import { generateSeed } from "@qubic.org/wallet"
import { toIdentity } from "@qubic.org/types"

const pool = createNodePool([
  "node1.qubic.org",
  "node2.qubic.org",
  "node3.qubic.org",
])

try {
  // 1. Fetch current tick
  const { tick, epoch } = await requestCurrentTickInfo(pool)
  console.log(`Epoch ${epoch}, tick ${tick}`)

  // 2. Check an entity balance
  const pk = identityToPublicKey(toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL"))
  const { entity, identity } = await requestEntity(pool, pk)
  const balance = entity.incomingAmount - entity.outgoingAmount
  console.log(`${identity}: ${balance} QU`)

  // 3. Build and broadcast a transaction directly over TCP
  const seed = generateSeed()
  const sourcePublicKey = publicKeyFromSeed(seed)
  const destinationPublicKey = new Uint8Array(32) // zero-address

  const unsigned = buildTransaction({
    sourcePublicKey,
    destinationPublicKey,
    amount: 0n,
    targetTick: tick + 5,
    inputType: 0,
  })
  const signed = await signTransaction(unsigned, seed)
  await broadcastTransaction(pool, signed)
  console.log("Transaction broadcast via TCP")
} finally {
  pool.close()
}
```
