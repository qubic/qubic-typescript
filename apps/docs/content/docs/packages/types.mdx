## Concepts

### Branded types

TypeScript's structural typing means a plain `string` and an `Identity` are assignable to each other — the compiler won't catch `wallet.buildTransfer({ destination: someRandomString })`. Brands add a phantom property that makes the types nominally distinct at compile time with zero runtime overhead.

```ts
type Identity = string & { readonly __brand: "Identity" }
```

You get an `Identity` either by calling `toIdentity(s)` (throws if invalid) or by asserting with `as Identity` (only do this when you know the value is valid).

### Constructors vs type guards

Use **constructors** (`toIdentity`, `toSeed`, `toTxHash`) at input boundaries — reading from a form, a file, a CLI argument. They throw a typed error on invalid input.

Use **type guards** (`isIdentity`, `isSeed`, `isTxHash`) in conditional branches where you need a boolean without throwing.

```ts
// At a boundary: throw early if bad input
const id = toIdentity(process.argv[2])

// In a conditional: check without throwing
if (isIdentity(raw)) {
  doSomethingWith(raw) // raw is now narrowed to Identity
}
```

### Error hierarchy

All SDK errors extend the abstract `QubicError` class. You can catch at the base level or at a specific subclass level.

```ts
try {
  const id = toIdentity(input)
} catch (e) {
  if (e instanceof InvalidIdentityError) {
    // Handle specifically
  } else if (e instanceof QubicError) {
    // Handle any SDK error
  }
}
```

## API reference

### Branded types

| Type | Format | Description |
|---|---|---|
| `Identity` | 60 uppercase chars | Qubic address derived from a public key |
| `Seed` | 55 lowercase chars | Private key material |
| `TxHash` | 60 lowercase chars | Transaction identifier |
| `Base64` | standard base64 | Encoded transaction payload for broadcast |
| `HexPublicKey` | 64 hex chars | 32-byte public key as a hex string |

---

### `toIdentity(s)`

Parses and validates a string as an `Identity`.

**Parameters**

| Name | Type | Description |
|---|---|---|
| `s` | `string` | The string to validate. Must be 60 uppercase characters. |

**Returns** `Identity`

**Throws** `InvalidIdentityError` — if the string does not match the 60-char uppercase pattern.

```ts
import { toIdentity } from "@qubic.org/types"

const id = toIdentity("CFBMEMZOIDEXQAUXYYSZIURADQLAPWPMNJXQSNVQZAHYVOPYUKKJBJUCTVJL")
```

---

### `toSeed(s)`

Parses and validates a string as a `Seed`.

**Throws** `InvalidSeedError` — if the string is not 55 lowercase characters.

---

### `toTxHash(s)`

Parses and validates a string as a `TxHash`.

<Callout>
  Transaction hashes from some APIs come back uppercase. Call `.toLowerCase()` before passing to `toTxHash`.
</Callout>

**Throws** `InvalidTxHashError` — if the string is not 60 lowercase characters.

---

### `isIdentity(s)` / `isSeed(s)` / `isTxHash(s)`

Type guard predicates. Return `true` if the string matches the format; `false` otherwise. Never throw.

```ts
import { isIdentity } from "@qubic.org/types"

const raw: string = getFromSomewhere()
if (isIdentity(raw)) {
  // raw is narrowed to Identity here
}
```

### `CONTRACT_INDEX`

Maps contract names to their on-chain index numbers. 27 contracts are defined.

```ts

console.log(CONTRACT_INDEX.QEARN)     // 9
console.log(CONTRACT_INDEX.QX)        // 1
console.log(CONTRACT_INDEX.QUOTTERY)  // 4
```

### Error classes

| Class | Thrown by |
|---|---|
| `QubicError` | Abstract base — never thrown directly |
| `InvalidIdentityError` | `toIdentity`, `identityToPublicKey` |
| `InvalidSeedError` | `toSeed`, `publicKeyFromSeed` |
| `InvalidTxHashError` | `toTxHash` |
| `InvalidBase64Error` | `toBase64` |

## Complete example

Validate an identity from the command line and display it:

```ts title="validate-identity.ts"
import { toIdentity, isIdentity, InvalidIdentityError } from "@qubic.org/types"

const input = process.argv[2]

if (!input) {
  console.error("Usage: bun run validate-identity.ts <identity>")
  process.exit(1)
}

try {
  const id = toIdentity(input)
  console.log("Valid identity:", id)
} catch (e) {
  if (e instanceof InvalidIdentityError) {
    console.error("Invalid identity — must be 60 uppercase characters")
  } else {
    throw e
  }
}
```
